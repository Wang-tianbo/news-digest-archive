### 1. GitHub Copilot app 正式 GA，成为跨平台桌面 agent 入口

### 2. GitHub Agent finder 上线，采用开放 ARD 规范做 agent 资源发现

- 发生了什么：GitHub 于 `2026-06-17 16:21 UTC` 发布 [Agent finder for GitHub Copilot now available](https://github.blog/changelog/2026-06-17-agent-finder-for-github-copilot-now-available/)。Agent finder 可以根据自然语言任务，从 MCP servers、skills、canvases、agents、tools 等 AI 资源索引中检索并排序可用能力；官方称它实现了开放的 Agentic Resource Discovery（ARD）规范，该规范由 Microsoft 与 Google、GoDaddy、Hugging Face、GitHub 等协作推进。
- 为什么重要：这把 agent 工具接入从“手工把所有资源塞进上下文”推进到“按任务动态发现、按组织策略约束”。如果 ARD 被更多 registry 和 AI client 采用，agent 生态会更像可治理的资源目录，而不是一组孤立插件。
- 来源：[GitHub Changelog - Agent finder for GitHub Copilot now available](https://github.blog/changelog/2026-06-17-agent-finder-for-github-copilot-now-available/)

### 3. Copilot Chat Auto mode 向所有用户开放，并引入动态模型路由
