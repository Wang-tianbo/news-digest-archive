## 今日最重要的 3 条更新

### 1. Anthropic 发布 `Claude Code v2.1.158`

- 发生了什么：`Claude Code v2.1.158` 于 `2026-05-30 10:42` Asia/Shanghai 发布，官方说明 Auto mode 现在可在 Bedrock、Vertex 和 Foundry 上用于 Opus 4.7 与 Opus 4.8，并可通过 `CLAUDE_CODE_ENABLE_AUTO_MODE=1` 开启。
- 为什么重要：这把 Claude Code 的自动模式推进到企业常见的托管模型环境。对组织采用来说，能否在 Bedrock、Vertex、Foundry 这类路径上保持一致能力，比只在默认渠道可用更关键。
- 来源：
  [Claude Code Release - v2.1.158](https://github.com/anthropics/claude-code/releases/tag/v2.1.158)

### 2. Gemini CLI nightly 修复 invalid `preferredEditor` spam loop

- 发生了什么：`google-gemini/gemini-cli` 于 `2026-05-30 10:45` Asia/Shanghai 发布 [v0.45.0-nightly.20260530.g013914071](https://github.com/google-gemini/gemini-cli/releases/tag/v0.45.0-nightly.20260530.g013914071)，主要包括防止 invalid `preferredEditor` 触发 spam loop。
- 为什么重要：这是典型低层体验修复。对 CLI agent 来说，配置错误导致的循环噪声会直接降低用户对自动化工具的信任。
- 来源：
  [Gemini CLI Release - v0.45.0-nightly.20260530.g013914071](https://github.com/google-gemini/gemini-cli/releases/tag/v0.45.0-nightly.20260530.g013914071)

### 3. Qwen Code nightly 修复 false "compressed turn" rewind 问题

- 发生了什么：`QwenLM/qwen-code` 于 `2026-05-31 08:40` Asia/Shanghai 发布 [v0.17.0-nightly.20260531.c699738f9](https://github.com/QwenLM/qwen-code/releases/tag/v0.17.0-nightly.20260531.c699738f9)，主要承接 false "compressed turn" error when mid-turn messages exist 的 rewind 修复。
- 为什么重要：这类修复与 Qwen Code v0.17.0 的压缩 / 恢复机制直接相关。新压缩策略进入稳定版后，相关边界错误会决定长会话是否可靠。
- 来源：
  [Qwen Code Release - v0.17.0-nightly.20260531.c699738f9](https://github.com/QwenLM/qwen-code/releases/tag/v0.17.0-nightly.20260531.c699738f9)
