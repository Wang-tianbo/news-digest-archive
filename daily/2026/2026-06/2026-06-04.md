## 今日最重要的 4 条更新

### 1. GitHub 发布 Copilot in VS Code May releases，Agents window、remote agents、AHP 与 session sync 进入更稳定产品面

- 发生了什么：GitHub 于 `2026-06-03` 发布 [GitHub Copilot in Visual Studio Code, May releases](https://github.blog/changelog/2026-06-03-github-copilot-in-visual-studio-code-may-releases)。官方称 VS Code May / early June release 覆盖 `v1.120` 到 `v1.123`，重点包括 Agents window 在 VS Code Stable 中 preview、remote agents over SSH / Dev Tunnels、Agent Host Protocol、session preferences persistence、session and Git flow improvements、session sync、Chronicle、多 session side-by-side、sandbox 中网络命令重试、air-gapped BYOK、custom endpoint provider、model picker by provider、BYOK token visibility、reasoning effort controls、utility model configuration、expanded terminal output compression 和 command risk assessment。
- 为什么重要：这说明 GitHub 正在把 Copilot agent 从“IDE 里的聊天 / 补全”推进到 `agent-first IDE surface`。Agents window、remote agents、session sync、Chronicle 和 BYOK 组合起来，正在把本地、远程、多模型、跨会话记忆和终端安全纳入一个工作流。
- 来源：
  [GitHub Copilot in Visual Studio Code, May releases](https://github.blog/changelog/2026-06-03-github-copilot-in-visual-studio-code-may-releases)

### 2. Claude Code v2.1.162 继续补 Remote Control、agents 可观测性、权限规则与后台会话恢复

- 发生了什么：`anthropics/claude-code` 于 `2026-06-04 05:31` Asia/Shanghai 发布 [v2.1.162](https://github.com/anthropics/claude-code/releases/tag/v2.1.162)。主要变化包括 `claude agents --json` 增加 `waitingFor`、`--tools` 显式 Grep / Glob 在 native builds 中生效、`/effort` 持久化确认、Remote Control footer pill、Windsurf 更名为 Devin Desktop，以及修复只读 config 目录启动静默 hang、WebFetch permission rules、Windows permission rules、stream-json / SDK 开头 Esc 丢失、MCP timeout 子 1000ms、LSP workspaceSymbol、agents 宽终端截断、background service restart attach、Ctrl+V image paste、backgrounding session 时后台服务失败导致会话丢失、跨会话消息在深层 TMPDIR 下失效等问题。
- 为什么重要：这是一组非常“后台 agent 真实运行”的修补。尤其是 `waitingFor`、Remote Control 持久提示、权限规则、启动错误显式化和跨会话消息修复，会让用户更清楚 agent 卡在哪里、谁在控制、哪些权限被允许或拒绝。
- 来源：
  [Claude Code Release - v2.1.162](https://github.com/anthropics/claude-code/releases/tag/v2.1.162)
