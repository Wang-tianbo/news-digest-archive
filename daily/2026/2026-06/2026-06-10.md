### 1. Anthropic 发布 Claude Fable 5 / Mythos 5，把前沿能力拆成通用访问与可信访问双轨

- 发生了什么：Anthropic 于 `2026-06-09` 发布 [Claude Fable 5 and Claude Mythos 5](https://www.anthropic.com/news/claude-fable-5-mythos-5)。官方称 Fable 5 是可面向通用用户开放的 Mythos-class 模型，软件工程、知识工作、视觉、科学研究等长复杂任务能力更强；同时对部分高风险请求采用保守 safeguards，可能转由 Claude Opus 4.8 响应。Mythos 5 是同一底层模型但在部分领域解除限制，先通过 [Project Glasswing](https://www.anthropic.com/glasswing) 面向少量 cyberdefenders 和基础设施提供方，并与美国政府合作。官方还给出价格：每百万 input tokens `10` 美元、output tokens `50` 美元。
- 为什么重要：这把“模型能力释放”变成分层访问问题。Anthropic 明确把高风险 cyber 能力放进 trusted access 轨道，而不是简单一刀切开放或封锁；这可能成为前沿模型公司处理安全、政府合作和企业高风险能力交付的模板。
- 来源：

### 2. Codex `0.139.0` 发布：Code mode 可调用 standalone web search，MCP schema 与 sandbox 约束继续增强

- 发生了什么：`openai/codex` 于 `2026-06-10 04:13` Asia/Shanghai 发布 [rust-v0.139.0](https://github.com/openai/codex/releases/tag/rust-v0.139.0)。Release notes 显示 Code mode 现在可直接调用 standalone web search，包括 nested JavaScript tool calls，并返回 plaintext search results；tool / connector input schemas 保留 `oneOf` / `allOf`，大 schema compaction 保留更多浅层结构；`codex doctor` 增加 editor 和 pager 环境诊断；plugin marketplace list JSON 增加 marketplace source，并可先返回缓存 catalog。修复项还包括 `resume --last` / `fork --last` prompt 解析、subagent MCP startup warning 归属、image edit 精确引用文件路径、thread resets 保留 cloud-managed requirements、sandbox 执行保留 approved escalation 并更一致执行 proxy-only networking。
- 为什么重要：Codex 正在把“能写代码的 CLI”扩展为可搜索、可接 richer MCP tools、可诊断、可治理、可插件化的本地 agent runtime。特别是 web search in code mode 和 schema 兼容性，会直接影响 agent 在复杂工具生态里的自主信息获取和工具调用质量。
- 来源：
  [Codex Release - rust-v0.139.0](https://github.com/openai/codex/releases/tag/rust-v0.139.0)
  [Codex compare - rust-v0.138.0...rust-v0.139.0](https://github.com/openai/codex/compare/rust-v0.138.0...rust-v0.139.0)
