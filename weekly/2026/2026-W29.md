## 本周主线

本周最强主线不是单个旗舰模型，而是 AI agent 从“能执行任务”继续转向“能被限制、追踪、恢复、计费、评估和纳入组织治理”。Claude Code、Codex、Gemini CLI、Qwen Code、Copilot CLI、Pydantic AI、Vercel AI SDK 和 Dify Agent 每天都在补权限、沙箱、工具状态、后台会话、workspace、memory、遥测和成本边界。

中国侧出现一个更强的模型级变量：Moonshot 发布 Kimi K3，并把 Kimi Code、API、开源、technical report 和下载入口放在同一发布叙事里。这让“中国前沿模型 + coding agent + 开源分发”的观察从单纯工程工具链，重新回到模型与开发者入口合流。

美国侧更明确地把 agent 推进企业控制面。GitHub 把 AI security detections、Copilot usage metrics、code review 配置和 Copilot CLI plan-mode 写保护串起来；Google 把 Gemini Enterprise、第三方模型选择和 Parallel Web Search grounding 组合成企业 agent 平台；Anthropic 则用 Claude Code 的连续 release 证明运行时安全已经是 coding-agent 核心能力。

研究前沿与产品事实形成互相校准：`Agent Hacks Agent`、`BackendForge`、`Workflow as Knowledge`、`Agora`、GPT-Red 和成本感知安全 agent 评测都在指向同一件事：未来 agent 的胜负不只看成功率，而要看可复用状态、工具纪律、成本、红队覆盖和真实工作流可验证性。

## 本周评论与判断

基于本周已存档样本的判断，AI 编程代理进入了“运行时治理密集修补期”。Claude Code 连续修 worktree 隔离、权限预览视觉欺骗、hook 决策、MCP 重连、后台会话、工具预算、shell / path analyzer、远程确认和 OpenTelemetry 字段；Codex 回滚 Guardian auto-review prompting 回归，又修 GPT-5.6 系列内置提示与 context window 元数据；Gemini CLI 开始处理 ReAct / prompt injection loops。这些都说明产品核心已经从“能写代码”转向“能解释边界、限制工具、留下审计线索”。

第二个判断是，Qwen Code 与 LobeHub 已经成为观察中文 agent runtime 的连续样本。Qwen Code 一周内从 nightly 到 stable，不断推进 Web Shell、多 workspace、artifact panel、SDK / daemon runtime、memory、session-info、review inline findings 和 readonly history replay；LobeHub 则持续把 Claude Code、MCP、browser、terminal、inbox、Composio connector、异构设备和长话题 UI 放入桌面工作台。它们还不能证明中国侧整体 agent runtime 成熟，但足以支撑 `china-open-agent-runtime` 从观察转为持续跟踪。

第三个判断是，企业 agent 控制面正在从安全策略扩展到使用指标、grounding、成本和团队配置。GitHub 的 PR AI security detections、Copilot usage metrics API 和 code review customizability，Google 的 Parallel Web Search grounding，Pydantic AI 的 cache hit ratio / OTel 字段，Vercel AI SDK 的 URL validation 和 tool lifecycle 修补，都在把 agent 从个人助手变成组织系统的一部分。

第四个判断是，Kimi K3 本周值得单独记住，但不能被过度外推。它的强度来自模型发布与 Kimi Code、开源入口、API 和英文工程社区关注同时出现；但真正是否改变格局，还要等权重可用性、technical report 细节、推理成本、第三方 coding benchmark、Kimi Code 真实项目表现和主流推理框架吸收情况。
