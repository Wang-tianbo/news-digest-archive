## 今日最重要的 5 条更新

### 1. GitHub Agentic Workflows 进入 public preview

- 发生了什么：GitHub 于 `2026-06-11` 发布 [GitHub Agentic Workflows is now in public preview](https://github.blog/changelog/2026-06-11-github-agentic-workflows-is-now-in-public-preview/)。官方称用户可以用自然语言 Markdown 定义 issue triage、CI failure analysis、documentation updates 等 reasoning-based tasks，Agentic Workflows 会编译成标准 GitHub Actions YAML，并复用现有 runner groups 与 policy constraints。安全设计包括 read-only default permissions、sandboxed container、Agent Workflow Firewall、safe outputs validation 和 threat detection job。
- 为什么重要：这把 coding agent 从“会话工具”推进到“可纳入 CI/CD 和组织策略的自动化层”。真正改变开发流程的不是 agent 能开 PR，而是它能否在组织已有权限、审批、runner 和审计框架下稳定运行。
- 来源：
  [GitHub Changelog - GitHub Agentic Workflows is now in public preview](https://github.blog/changelog/2026-06-11-github-agentic-workflows-is-now-in-public-preview/)

### 2. GitHub Agentic Workflows 支持 `GITHUB_TOKEN`，并补齐组织计费与成本控制

- 发生了什么：GitHub 于 `2026-06-11` 发布 [Agentic workflows no longer need a personal access token](https://github.blog/changelog/2026-06-11-agentic-workflows-no-longer-need-a-personal-access-token/)，Agentic Workflows 可使用 GitHub Actions 内置 `GITHUB_TOKEN`，不再要求长期 PAT；组织仓库内的 agentic workflow 可通过 `copilot-requests: write` 把 AI credits 直接计入组织。GitHub 同日还发布 [AI usage report updates](https://github.blog/changelog/2026-06-11-ai-usage-report-updates/)，把 AI Credits usage 对齐到标准报表字段 `quantity` 和 `gross_amount`。
- 为什么重要：这是 agent 自动化规模化必须补齐的运营层。PAT 移除降低密钥管理风险，组织计费和 usage report 字段对齐则让 agent 成本进入企业财务和平台工程可管理范围。
- 来源：
  [GitHub Changelog - Agentic workflows no longer need a personal access token](https://github.blog/changelog/2026-06-11-agentic-workflows-no-longer-need-a-personal-access-token/)
  [GitHub Changelog - AI usage report updates](https://github.blog/changelog/2026-06-11-ai-usage-report-updates/)

### 5. OpenAI Agents SDK `0.17.5` 暴露 sandbox error retryability

- 发生了什么：`openai/openai-agents-python` 于 `2026-06-11 12:11` Asia/Shanghai 发布 [v0.17.5](https://github.com/openai/openai-agents-python/releases/tag/v0.17.5)。Release notes 中最值得记录的是 `fix: expose sandbox error retryability`，同时修正 tool-end hook result typing、SpeechGroupSpanData `__slots__`、Modal sandbox extra 版本，并补充 MongoDB session example 等文档。

- 来源：
  [OpenAI Agents SDK Python Release - v0.17.5](https://github.com/openai/openai-agents-python/releases/tag/v0.17.5)

- 被强化了什么：企业采用的关键已经不只是模型能力，而是 agent 能否被批准、计费、审计、限额和恢复。
- 被削弱了什么：只有 release cadence、没有清晰 release note 的 alpha 版本不应被过度解释；Codex `0.140` 本期只记录节奏。
