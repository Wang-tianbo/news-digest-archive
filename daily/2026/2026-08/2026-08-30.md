## AI 研究前沿

### 1. WikiSkill：把 agent 经验沉淀成持久 wiki，再反哺 skill evolution

- 类型：论文
- 研究问题：agent 从执行历史中自动演化 skill 时，如何避免经验散落在优化轨迹里、无法跨迭代和跨模型复用。
- 核心思路：WikiSkill 把原始执行经验、累积知识和可执行 skills 分开，持续把经验整合进 persistent knowledge base，再让后续 skill 更新复用这些知识。
- 为什么可能影响未来：它直接对应当前 coding agent 的长期记忆、技能沉淀和跨模型迁移问题；如果结果能复现，agent 平台可能不再只保存 transcript，而是保存可演化知识资产。
- 局限 / 待验证点：论文仍需第三方复现；不同任务域里的 wiki 维护成本、错误知识清理和权限边界还不清楚。
- 研究成熟度：早期论文
- 可复现状态：论文原文可查；本次未验证代码
- 原文链接：[arXiv:2608.27454](https://arxiv.org/abs/2608.27454)
- 权威解读：暂无
- 我的判断：它是本期 community memory / OpenContext 信号的研究版，值得后续看是否进入真实 coding-agent skill 系统。

### 2. Instruct-to-Act：VLM 做高层规划，world-model controller 做低延迟控制

- 类型：论文
- 研究问题：预训练 VLM 擅长从指令和观察生成高层计划，但在陌生环境里直接输出可靠、低延迟动作序列仍不稳定。
- 核心思路：论文把系统拆成 VLM planner 和 world-model controller，用 VLM 生成稀疏高层文本指令，用训练后的 controller 高频执行动作，并通过 synthetic instructions relabel controller rollouts 来让控制器可被语言指挥。
- 为什么可能影响未来：它把 agent 架构里的“慢规划 / 快执行”拆分讲得很清楚，对具身、多 agent 和未来 GUI / robotics agent 都有参考价值。
- 局限 / 待验证点：主要在 embodied / multi-agent environments 中评估，和通用软件 agent 的迁移关系仍需验证。
- 研究成熟度：COLM 2026 conference paper
- 可复现状态：论文和项目页可查；本次未验证代码
- 原文链接：[arXiv:2608.26788](https://arxiv.org/abs/2608.26788)
- 权威解读：[project page](https://zinengtang.github.io/instruct-to-act/)
- 我的判断：它和 Neurometric 的 tool-calling SLM 观点有同构关系：复杂 agent 未必由一个大模型端到端完成，拆出专门执行层可能更可靠、更便宜。

- 延续了什么：agent runtime governance、MCP 安全、权限边界、review evidence 和会话 / 任务持久化继续是主线。
