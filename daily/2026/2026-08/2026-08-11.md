## AI 研究前沿

### 1. SkillProx: Self-Evolving Agent Skills via Proximal Textual Gradient Descent

- 类型：论文
- 研究问题：agent 如何把常见任务沉淀成可复用技能，并持续自我改进。
- 核心思路：用 textual gradient descent 迭代文本技能，而不是只靠权重更新。
- 为什么可能影响未来：如果技能真的能像文本资产一样演化，agent runtime 的复用率会明显上升。
- 局限 / 待验证点：仍然是早期论文，跨任务泛化和长期稳定性还要看复现。
- 研究成熟度：早期论文
- 可复现状态：未验证
- 原文链接：[arXiv:2608.07449](https://arxiv.org/abs/2608.07449)
- 权威解读：暂无
- 我的判断：这条线和今天的 Qwen Code / Claude Code 节奏很合拍，说明技能层会继续上移。

### 2. TEPA: Revoking Stale Memories for Conflict-Robust Language Agents

- 类型：论文
- 研究问题：agent 的长期记忆如何在世界变化后撤销过期内容，避免冲突记忆污染行为。
- 核心思路：显式撤销 stale memories，让记忆生命周期可控。
- 为什么可能影响未来：长任务 agent 一旦进入真实工作流，记忆管理会和工具调用一样重要。
- 局限 / 待验证点：仍需看实际任务、真实数据更新和多轮工作流中的效果。
- 研究成熟度：早期论文
- 可复现状态：未验证
- 原文链接：[arXiv:2608.07429](https://arxiv.org/abs/2608.07429)
- 权威解读：暂无
- 我的判断：这条研究直接补上了今天“运行时治理”的另一半，也就是记忆治理。
