## 本周主线

- 本周最重要的变化是：前沿模型发布重新成为主线，但它不是孤立的模型 headline，而是和受限预览、Codex/API 首发、安全检查、价格 / 缓存、subagent 编排和算力供给绑定在一起。

## 本周评论与判断

- 基于本周样本的判断，AI 竞争正在进入“强模型的受控交付”阶段。GPT-5.6 的重点不只是 Sol 的能力，而是 OpenAI 同时给出 API / Codex 预览、ChatGPT 暂不开放、价格与缓存、额外安全检查、system card 和 compute 基础设施叙事。这比单独发布一个模型更能影响企业采用节奏。
- 基于本周样本的判断，Codex 的战略位置被显著抬高。过去几周 Codex release 主要证明它在补预算、插件、MCP、多 agent、代理认证和安全审批；本周 GPT-5.6 把 Codex 放入前沿模型预览入口，说明 coding agent 已经从“模型能力的使用场景”变成“模型能力的首批交付与治理场景”。
- 基于本周样本的判断，GitHub 是本周最完整的平台化样本。它既有模型层的 MAI-Code-1-Flash 和 auto model selection，也有组织层的 adoption metrics、Enterprise agents、marketplace allowlist、Jira GA，还有终端 / 桌面层的 Copilot CLI skills、GitHub Desktop worktree 和 conflict resolution。
- 基于本周样本的判断，Claude Code 与 Qwen Code 的价值不在单个 release 名称，而在它们把后台任务、MCP、权限、插件、telemetry、daemon、Web Shell、workspace boundary 和 computer-use 执行层持续工程化。这里的真实竞争点是团队是否敢让 agent 长时间在真实仓库、真实网络和真实权限下运行。
- 基于本周样本的判断，推理 runtime 应进入更高权重观察。SGLang `0.5.14` 和 llama.cpp 连续 release 说明模型发布后的成本、吞吐、硬件覆盖、结构化工具调用、本地 backend 和私有部署，正在变成模型公司竞争力的一部分。
