## 今日最重要的 5 条更新

### 1. Cursor for iOS public beta：移动端成为 always-on agents 的控制面

- 发生了什么：Cursor 于 `2026-06-29` 发布 [Cursor Mobile App for iOS](https://cursor.com/changelog/ios-mobile-app) 和配套 [产品博客](https://cursor.com/blog/ios-mobile-app)。官方说明称，Cursor for iOS 在所有 paid plans 上进入 public beta，可在手机上选择 repo、启动 cloud agent、语音输入、使用 slash commands、通过 Remote Control 指挥本机 agent、接收 Live Activities / push notifications，并从手机查看 demos、screenshots、logs、diffs，留下后续指令或直接 merge PR。Teams / Enterprise 的 Remote Control 需要管理员在 Dashboard 启用。
- 为什么重要：这把 coding agent 从“桌面内交互”推进到“跨设备长任务管理”。如果 agent 的常态是长时间运行、等待 review、需要补充上下文或人工批准，那么手机端的通知、接管和 PR review 会变成真实工作流的一部分。
- 来源：[Cursor Changelog - Mobile App for iOS](https://cursor.com/changelog/ios-mobile-app)、[Cursor Blog - Build from anywhere with Cursor for iOS](https://cursor.com/blog/ios-mobile-app)

### 2. Claude Code `2.1.196`：组织默认模型、MCP pending approval 与后台任务恢复继续补治理边界

- 发生了什么：Anthropic 于 `2026-06-30 07:27:32` Asia/Shanghai 发布 [Claude Code `v2.1.196`](https://github.com/anthropics/claude-code/releases/tag/v2.1.196)。Release notes 包括组织默认模型支持、会话默认可读名称、chat 中可点击文件附件；安全侧，`claude mcp list/get` 不再启动由仓库 `.claude/settings.json` 自批准的 `.mcp.json` servers，untrusted workspaces 显示 pending approval；同时修复 background job 唤醒误删对话、parallel requests 下 rate-limit telemetry 过计、Remote sessions server restart 后自动恢复、MCP OAuth `invalid_scope`、`claude agents --dangerously-skip-permissions` bypass disclaimer、background shells 在 Windows 上移交而非被杀、以及 stream idle watchdog 默认开启等。
- 为什么重要：Claude Code 的重点继续从功能扩展转向团队可控性和长期任务可靠性。组织默认模型、MCP 权限、后台任务恢复、Remote session crash recovery 和 stream watchdog，都是企业把 agent 放进真实开发流程前必须补齐的运行时边界。
