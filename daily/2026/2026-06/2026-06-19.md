## 今日最重要的 5 条更新

### 1. OpenAI Codex `0.141.0` 稳定版发布，远程执行与插件 MCP 进入正式版本

- 发生了什么：`openai/codex` 于 `2026-06-18 12:43` Asia/Shanghai 发布 [rust-v0.141.0](https://github.com/openai/codex/releases/tag/rust-v0.141.0)。Release notes 显示远程 executors 现在使用 authenticated、end-to-end encrypted Noise relay channels；跨平台 remote execution 保留 executor-native working directories 与 shells；selected executor plugins 可按 thread 激活 stdio MCP servers；app-server clients 可列出 child threads、关联 external-agent imports、读取 / 兑换 rate-limit reset credits；realtime clients 可显式 append speech；TUI input prompts 可 inactivity auto-resolve。
- 为什么重要：这把前几天 alpha 中出现的远程执行、plugin MCP、realtime 和 rate-limit 治理信号收束成稳定版。对 Codex 来说，竞争点越来越不是单次补全，而是远程环境、插件工具、安全传输、跨 OS 文件路径和长任务会话的可靠性。
- 来源：[Codex Release - rust-v0.141.0](https://github.com/openai/codex/releases/tag/rust-v0.141.0)

### 4. Cursor Automations 升级：自然语言配置、Slack / GitHub triggers、computer use 与 nested subagents

- 发生了什么：Cursor 于 `2026-06-18` 发布 [Improvements to Cursor Automations](https://www.cursor.com/changelog/06-18-26)。官方称 Cursor Automations 是 always-on agents，本次新增 `/automate` skill，可用自然语言描述自动化任务并由 Cursor 配置 triggers、instructions 和 tools；新增 GitHub / Slack triggers，其中 Slack 可通过指定 emoji reaction 触发 automation；同时支持 computer use。该版本还强化 local / cloud handoff、SDK JSONL / custom stores、requestId run correlation、nested subagents、HTTP/1.1 cloud streaming、Composer 2 自动路由到 Composer 2.5 等。
