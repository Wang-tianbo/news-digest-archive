## AI 研究前沿

### 1. Discriminative World Models for Web Agents

- 类型：论文
- 研究问题：Web agents 在 test-time action selection 中会预测候选动作后的网页状态，再交给 ranker / PRM 排序；但传统 next-state prediction 目标不一定让预测状态足够区分不同候选动作。
- 核心思路：论文提出 predicted-state matching，让预测表示必须把真实后继状态和替代动作后继状态区分开；数据来自 WebArena Go-Browse trajectories 的 branching 决策点，并在 WebPRMBench 和 WebArena-Lite 上验证 action ranking 和 end-to-end success。
- 为什么可能影响未来：如果 web agent 的世界模型目标从“像不像真实页面”转向“能否区分哪个动作更好”，浏览器 agent 的规划、回滚和自动操作可能会更可控。
- 局限 / 待验证点：结果仍依赖 WebArena 系列任务和构造出的 branching 数据；真实网页中的动态状态、登录态和权限边界仍待验证。
- 研究成熟度：早期论文
- 可复现状态：论文原文可查；本次未复跑
- 原文链接：[arXiv:2609.02885v1](https://arxiv.org/abs/2609.02885v1)
- 权威解读：暂无
- 我的判断：它和 Cursor / Claude / Qwen 的 browser / computer-use 趋势强相关。agent 越能操作网页，越需要把“下一步会发生什么”建模成可排序、可审计的中间对象。

### 2. SafeEvolve：从 agent 经验中共同演化 harness 和 policy

- 类型：论文
- 研究问题：LLM agent 的安全表现同时由模型和 harness 决定；只改外部 harness 或只做 policy optimization 都难以同时覆盖 runtime control 与模型内化安全行为。
- 核心思路：SafeEvolve 用已完成 on-policy trajectories 中的安全经验，持续更新 safety prompt 和 hierarchical skills 等 bounded harness artifacts，同时用 harness-use SFT 与 harness-augmented RL 改善模型在多步探索中的安全行为。
- 为什么可能影响未来：它把安全经验变成可审计、可回滚的 harness 组件，再和模型训练结合，和今天产品侧的 managed settings、permission rules、approval classifier 是同一方向。
- 局限 / 待验证点：论文报告在 agentic safety benchmarks 上改善安全-效用权衡，但真实产品里的工具权限、组织策略和攻击面更复杂。
- 研究成熟度：早期论文
- 可复现状态：论文原文可查；本次未复跑
- 原文链接：[arXiv:2609.02786v1](https://arxiv.org/abs/2609.02786v1)
- 权威解读：暂无
- 我的判断：这是本期最贴近“runtime governance 能不能进入训练闭环”的研究项。它把 safety prompt / skills 从静态规则变成经验驱动的工程资产。

### 3. Repo-To-Skill：把 GitHub 仓库压缩成 agent 可复用技能

- 类型：论文
- 研究问题：自主研究 agent 需要规划、执行、记忆和验证，但领域操作知识常散落在仓库和论文里，太长、太散，不能每次任务都完整读入。
- 核心思路：论文提出 DisCo，把常用 ML 仓库和具体任务所需知识蒸馏成 compact verified skills；作者称 AREX-Skill Library 覆盖 1,000 个 ML 仓库、5,000+ verified skills、20 个领域和 178 个能力族，并在固定 backbone / harness / execution budget 下提升多个研究 benchmark。
- 为什么可能影响未来：如果 repo-to-skill 稳定，agent 的能力扩展会从“临时读仓库”转向“把操作知识编译成版本化技能库”，也会改变开源项目如何被 agent 消化。
- 局限 / 待验证点：论文中的 skill 质量、覆盖偏差、验证成本和跨仓库泛化仍需第三方复现；固定 budget 的提升不能直接外推到所有工程任务。
- 研究成熟度：早期论文
- 可复现状态：论文原文可查；本次未复跑
- 原文链接：[arXiv:2609.02749v1](https://arxiv.org/abs/2609.02749v1)
- 权威解读：暂无
- 我的判断：这和 Claude / Codex / Cursor / Qwen 都在做的 skills / plugins / marketplace 方向形成研究侧支撑。长期看，技能库可能会成为 agent 产品的第二层模型目录。

- 延续了什么：agent runtime governance、tool / MCP 边界、长上下文成本、审批和执行证据仍是主线。
- 新出现了什么：GPT-6 Astra 把 critical cyber capability 和 access program 推到前台；Cursor self-hosted machines 把执行平面拉回企业侧；Qwen Code 稳定版开始系统化工作区记忆和 workflow 控制。
- 被削弱了什么：只有 tag、缺少具体 release body 的高频 CLI / RC 更新解释力继续下降；单纯“新模型接入”也不再足够，必须看它如何进入权限、上下文和成本控制链。
