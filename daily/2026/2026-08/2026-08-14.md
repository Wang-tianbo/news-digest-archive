### VAKRA：企业 agent 评测开始把 API、检索和 tool-use policy 放到同一任务里

- 类型：benchmark
- 研究问题：企业 agent 不只要会调用单个 API，还要跨结构化 API、文档检索和自然语言 tool-use policy 做多跳推理；现有 benchmark 往往把这些能力拆开测。
- 核心思路：论文提出 VAKRA，包含 62 个领域中超过 8,000 个可执行 API，并设置 API interaction、多跳结构化 API 推理、多源检索与 policy-constrained tool use 三类难度。预测 tool calls 通过重新执行 live APIs 验证。
- 为什么可能影响未来：如果评测从“会不会调用工具”转向“能否在政策约束下跨 API 和检索源完成任务”，agent 平台的竞争会更接近真实企业流程，也会暴露 entity disambiguation、cross-source grounding 和 unanswerable query 判断的短板。
- 局限 / 待验证点：这是早期 benchmark；本期只核验 arXiv 原文与其公开代码 / 数据链接，未运行复现，也未确认不同 harness 下的泛化表现。
