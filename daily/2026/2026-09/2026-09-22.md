## AI 研究前沿

### 1. CodeMidas：从已有代码自动构造 coding-agent RL 环境

- 类型：论文
- 研究问题：如何在不依赖 issue / commit 等开发痕迹的情况下，从开源代码本身构造可执行、可验证的 coding-agent 强化学习环境。
- 核心思路：CodeMidas 让 agent 探索已有代码功能、生成行为规范、构造基于原始代码执行的测试，并用执行检查和多次 rollout 过滤任务，最终从 3,185 个开源代码库构造 5,545 个训练任务。
- 为什么可能影响未来：如果可验证训练环境可以从代码本身规模化生成，coding agent 的 RL 数据瓶颈会从“找人工 issue”转向“自动挖掘软件行为”。
- 局限 / 待验证点：仍需验证任务质量、测试是否覆盖真实需求，以及不同语言 / 域的泛化；论文结果不等于所有真实仓库可直接自动生成可靠 verifier。
- 研究成熟度：早期论文
- 可复现状态：论文公开，代码复现状态待查
- 原文链接：[arXiv:2609.22068](https://arxiv.org/abs/2609.22068v1)
- 权威解读：暂无
- 我的判断：这是本期最值得放进 coding-agent 训练路线的研究信号，因为它把“代码库本身就是环境生成材料”讲得更具体。

### 2. Designer-RSI：用用户流量演化 agentic design 的程序记忆

- 类型：论文
- 研究问题：图形设计这类长链、多工具、难以程序化判分的 agent 任务，如何在不更新模型权重、没有人工标签的条件下持续适应。
- 核心思路：论文让冻结 frontier model 操作 230 多个设计软件工具，把成功和失败轨迹沉淀为外部 natural-language skill memory，并通过 widening / deepening 与 replay gate 控制新增或修订程序记忆。
- 为什么可能影响未来：它把“技能库 / procedural memory”从 coding agent 扩到可编辑设计软件，说明 agent 的长期资产可能不是 prompt，而是可审计、可回放、可回滚的外部技能记忆。
- 局限 / 待验证点：自动评分、用户流量样本分布和设计质量评估仍需更多第三方验证；论文结果不应直接外推到所有 creative workflow。
- 研究成熟度：早期论文
- 可复现状态：论文公开，未确认第三方复现
- 原文链接：[arXiv:2609.22086](https://arxiv.org/abs/2609.22086v1)
- 权威解读：暂无
- 我的判断：它和 Qwen Code / Claude Code / Codex 的 skills 方向同频：agent 进步可能越来越依赖外部程序记忆和经验库，而不是每次重新从上下文里推理。
