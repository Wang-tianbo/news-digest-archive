## AI 研究前沿

### 1. Agentic Societies Need a Social Harness：多 agent 协作需要社会层 harness

- 类型：论文
- 研究问题：当多个 AI agent 代表不同 principals、跨信任边界自主协作时，只给每个 agent 配个人 harness 是否足够。
- 核心思路：论文实验显示，即使 agent 诚实且胜任，现有 harness 和消息原语也会导致协作结果不佳；恶意或故障 agent 还能利用通信漏洞拖延协作、影响结果或追求有害目标。作者提出 social harness 分层架构，用于约束 inter-agent interaction。
- 为什么可能影响未来：这直接补上本期 Qwen cross-session messaging、ACP child admission 和 workflow correlation 的研究侧风险框架：agent 之间不是只要能通信，还要有社会层协议、验证和失败隔离。
- 局限 / 待验证点：早期论文，实验场景与真实企业 agent 网络仍有距离，social harness 具体产品化接口尚待验证。
- 研究成熟度：早期论文
- 可复现状态：论文公开，未确认第三方复现
- 原文链接：[arXiv:2609.17527](https://arxiv.org/abs/2609.17527)
- 权威解读：暂无
- 我的判断：这篇最有价值的不是提出新名词，而是提醒多 agent 系统的治理单位应从单个 agent 扩展到通信关系和协作协议。

### 2. ScienceBuddy：研究 agent 的自我改进需要同时改 harness 和模型

- 类型：论文 / 开源工作区
- 研究问题：科学研究 agent 如何从研究者日常请求、反馈和执行证据中持续改进，而不是只做一次性 benchmark。
- 核心思路：ScienceBuddy 提出 interactive scientific research workspace，并用 recursive-in-recursive self-improvement 同时改进 harness 和模型：内层固定模型改 harness，外层在改进后的 harness 下训练模型。
- 为什么可能影响未来：它把 agent 改进从单模型 RL 推到「任务、rubric、执行证据、harness 迭代」的闭环，更接近真实科研工作流。
- 局限 / 待验证点：仍是论文与案例研究；需要看开源代码、数据、rubric 和模型训练结果是否能被外部复现。
- 研究成熟度：早期论文 / 系统原型
- 可复现状态：论文公开，候选称已 release，但本期未完成代码复现
- 原文链接：[arXiv:2609.17523](https://arxiv.org/abs/2609.17523)
- 权威解读：暂无
- 我的判断：这条研究线和 Vercel evaluation model、Claude / Qwen workflow telemetry 同向：agent 能力的提升越来越依赖可积累的执行证据。

### 3. JustFit：本地长上下文 agent 的瓶颈正在变成状态管理

- 类型：论文
- 研究问题：开源权重模型在本地编码和推理场景中如何承载长上下文与执行状态，而不被笔记本内存限制。
- 核心思路：JustFit 基于 MLX，组合 KVExec、PhaseSwap 和 StateTrans，实现压缩 KV 执行、组件驻留和状态保持的 serving transitions。论文报告在 24 GiB M4 Pro MacBook 上用 Qwen3.8-27B MXFP4 完成 196,608 input + 16,384 output tokens。
- 为什么可能影响未来：如果这类方法成立，本地 coding agent 的竞争会从「能否跑模型」转向「能否保存长上下文、执行状态和切换状态」。
- 局限 / 待验证点：目前是单篇论文自报，需要第三方复现、更多模型和实际 coding-agent 工作负载测试。
- 研究成熟度：早期论文 / runtime 原型
- 可复现状态：论文公开，未确认第三方复现
- 原文链接：[arXiv:2609.17475](https://arxiv.org/abs/2609.17475)
- 权威解读：暂无
- 我的判断：它和云端 agent governance 是同一问题的本地版本：长任务的关键不是一次生成，而是状态如何被压缩、换入、恢复和验证。
