## 本月结论

- 2026 年 6 月最重要的阶段性变化是：`AI agent 正在从个人开发工具，变成可被组织配置、审计、计费、远程托管和跨设备接管的工作系统。`
- GitHub 是本月平台化最强样本。Copilot 从 SDK、sandbox、Agent tasks REST API、Agentic Workflows、enterprise-managed plugins、Auto mode、usage metrics、Jira、Desktop、CLI、code review 和 adoption metrics 一路推进到组织控制面。
- OpenAI 的月度主线有两层：Codex release 流持续补 archive、remote-control、cloud-managed config、plugin JSON、multi-agent、MCP、预算、代理网络和安全审批；月底 GPT-5.6 Sol / Terra / Luna 又把前沿模型能力和 API / Codex 受限预览、额外 safety checks、价格 / 缓存、算力约束接在一起。
- Anthropic 的 Claude Code 继续在长任务真实边界上积累优势：background agents、Remote Control、managed settings、fallbackModel、MCP policy、shell classifier、telemetry、plugin consent 和组织默认模型，构成了“无人值守 agent 如何可控运行”的连续样本。
- Qwen Code 是中国侧最连续、最可复盘的公开 coding agent runtime 样本。6 月从 `0.17` 到 `0.19` 系列持续推进 memory pressure、daemon、ACP、workflow、MCP resources、Web Shell、permissions、skills、telemetry、Computer Use 和 provider protocol。
- Google 本月不是基础模型 headline 的主角，但 Gemini API 模型生命周期、Gemini CLI skill 安全、tool registry、air-gapped identity、MCP 和 streaming 能力都说明其 agent / API 边界仍在收紧。
- 推理基础设施在 6 月从“外围观察”升格为主线变量。vLLM、SGLang、llama.cpp 围绕 DeepSeek-V4、MiniMax-M3、Qwen / GLM parser、GB300、MoE、OpenCL / CUDA / Vulkan / OpenVINO / Hexagon 的更新，直接影响开源模型和私有化 agent backend 的生产可用性。
- 本月最该降低权重的是“无部署治理的基础模型 headline”。强模型仍然重要，但真正改变格局的是模型如何被安全、受限、可计费、可审计地交付给 agent 和企业工作流。

## 本月评论与判断

- 基于本月样本的判断，`agent_runtime_governance` 已经不是宽泛标签，而是 coding agent 企业采用的中心问题。权限、MCP、插件、后台任务、shell 安全、telemetry、proxy、session、budget、model policy 和组织默认值在多家公司、多周报中连续出现。
- 基于本月样本的判断，GitHub 的优势正在从“默认开发入口”升级为“组织 agent 控制面”。它能把 IDE、CLI、Desktop、Actions、Jira、code review、usage metrics、模型路由和企业插件标准放进同一治理面，这是其他单点 agent 工具较难复制的结构优势。
- 基于本月样本的判断，OpenAI 正在把 Codex 放到更高战略位置。Codex 不只是 coding CLI，而是 GPT-5.6 预览入口、企业部署入口、安全修复工作流入口和多 agent runtime 底座。
- 基于本月样本的判断，Anthropic 的 Claude Code 不靠单次大发布制造强信号，而是用高频 release 把长任务失败面逐步产品化。它的长期价值在于定义后台 agent、权限继承、插件同意、shell 分类和遥测这些默认语义。
- 基于本月样本的判断，Qwen Code 值得继续作为 `china-open-agent-runtime` 核心台账，而不应被简单外推为“中国侧整体领先”。它强在公开节奏和工程韧性，仍需观察团队部署文档、企业策略、审计能力和其他中国厂商同级样本。
- 基于本月样本的判断，`open_inference_runtime` 应从外围补充升格为持续主题。推理框架对新模型架构、工具调用、KV cache、MoE、量化和多硬件的支持，正在决定模型能否进入本地 agent、企业私有化和云端 serving。

## 本月判断复盘

### 被验证的判断

- `AI 编程代理竞争下沉到运行时和治理` 被强验证。Codex、Claude Code、Qwen Code、Gemini CLI、Copilot CLI 和 GitHub Copilot 都在围绕权限、后台任务、MCP、插件、telemetry、budget、session 和安全审批持续发版。
- `coding-agent-platformization` 被 GitHub 和 OpenAI 强验证。Copilot 的 SDK / Agent tasks API / Agentic Workflows / Desktop / Jira / metrics 与 Codex 的 remote-control / plugin / multi-agent / GPT-5.6 入口共同说明平台化已经进入组织层。
- `china-open-agent-runtime` 被 Qwen Code 连续验证。6 月多次 stable 与 nightly 形成可复盘 release 流，主题从长会话韧性扩展到 daemon、Web Shell、permissions、MCP resources、skills 和 Computer Use。
- `MCP tooling layer` 被继续验证。GitHub MCP Server、Codex MCP tool search、Claude MCP login / OAuth retry、Qwen MCP resources、Gemini tool registry 和 Copilot CLI MCP OAuth refresh 都说明 MCP / tool registry 已进入主流 agent 底层。

### 被修正的判断

- `基础模型 headline 解释力下降` 需要改写。没有部署治理的模型 headline 解释力下降，但 GPT-5.6 这种绑定 Codex / API 入口、安全检查、价格、缓存、system card 和算力约束的前沿模型发布，重新成为强主线。
- `enterprise_agent_infra` 需要从企业销售渠道改写为 `enterprise_agent_platform`。本月真正持续的事实不是合作新闻本身，而是 usage credits、runner、content exclusion、desktop control、Auto mode、code review、resource discovery、CI / Jira / PR metrics 等组织工作流基础设施。
- `agent_context_standardization` 本月应保持观察而非升格。`AGENTS.md`、copilot instructions、MCP resources 和 project settings 有连续信号，但强度低于插件治理、MCP 认证、成本观测和受控模型交付。
- 对中国侧的判断需要继续克制。Qwen Code 很强，但中国基础模型公司整体在多个窗口偏静默，月报只能确认 Qwen Code 样本，而不能直接确认中国侧整体 agent runtime 已经形成集团式优势。

### 新形成的阶段性共识

- `前沿模型发布 = 能力 + 访问策略 + 安全治理 + 成本模型 + 算力约束 + agent 入口`，不再只是模型名和 benchmark。
- `组织级 agent 控制面` 正在成为平台公司竞争焦点，核心对象包括模型路由、插件市场、MCP、预算、审计、代码审查、Jira / Actions / Desktop / CLI 入口和团队指标。
- `长任务 agent` 的真实护城河在后台任务恢复、权限继承、shell 安全、session 持久化、worktree / workflow 隔离、telemetry 和失败可见性。
- `推理 runtime` 已经进入 AI 主线。DeepSeek、MiniMax、Qwen、GLM 等模型能否进入 agent backend，很大程度取决于 vLLM、SGLang、llama.cpp 等 serving 层的适配速度和复现质量。

### 本月噪声

- 无细节 alpha / nightly cadence 只能作为 release 节奏佐证，不能单独支撑强判断。
- 单纯“模型发布 / 项目活跃 / 页面入口变化”如果没有官方 changelog、release note、系统卡、文档或部署路径，不应进入月报主线。
- 与 AI 主线没有明确反作用的泛科技外围变量不应写入月报；本月保留的外围变量主要是算力、安全治理和推理 runtime，因为它们直接影响模型与 agent 的可用性。
