## 三、重点主题

### 大模型

- 新模型发布、升级、开源、API 能力变化
- 推理、多模态、长上下文、工具调用、Agent 能力
- 价格、性能、延迟、部署策略变化

### AI 编程代理

- Codex 及 OpenAI 相关博客、研究、产品更新
- Claude Code 及 Anthropic 相关博客、研究、产品更新
- GitHub Copilot、Cursor、Devin、Gemini CLI 等开发者工具
- 代码生成、代码审查、终端代理、IDE 集成、自动化研发流程

### 生态与基础设施

- 推理框架、评测框架、Agent 框架、RAG 工具链
- vLLM、Transformers、LangChain、LlamaIndex、OpenHands 等关键开源

### 市场与政策

- 融资、并购、重大合作
- 监管、版权、数据、出口限制、开源许可变化

### AI 外围关键变量

- 算力、半导体、HBM、先进制程、封装、服务器供给
- 云平台模型接入、数据中心、电力、推理容量与成本
- 安全、滥用、治理框架、企业权限与审计能力
- 企业采用、组织变革、开发者生产率、岗位与流程变化
- 医疗、教育、科研、政务等重点行业的高价值 AI 落地

### AI 圈博主

- 中文互联网与全球范围内活跃 AI 博主、技术工作者、研究者、创业者及关键人物
- 博客、RSS / Atom、Substack、GitHub、公众号公开页、长文、公开访谈中表达的高价值线索、判断、困惑、分歧与方法论
- 暂不纳入 X-only 来源；如果某个账号只有 X 入口，当前只能标记为访问受限，不能据此判断“没有新增”
- 对 AI 编程、模型竞争、组织采用、研究范式、产品形态有复盘价值的信息线索、观点判断、方法论或实践复盘
- 观点 / 线索源只作为线索和思想信号，不作为事实确认来源

### AI 研究前沿

- 前沿论文、研究博客、benchmark、eval、开源实现和实验室动向
- 对模型能力、Agent、推理、训练、评测、数据、系统、具身智能等方向有未来预判价值的研究信号
- 研究条目必须保留论文或研究动向原文链接
- 权威人士、作者、研究员、核心开发者或可信技术博主的解读可以作为辅助材料，但不能替代原文

## 四、来源优先级

1. 官方博客、官方公告、官方研究页面
2. 官方 GitHub 仓库、Release、Changelog
3. 论文原文、研究博客、benchmark / eval 原始页面、开源实现仓库
4. 官方社交账号或开发者文档
5. 高质量媒体与行业分析
6. 社区讨论与二手整理

## 五、入选标准

- 对模型能力、产品格局、开发者工作流有实质影响
- 出自重点公司或关键开源项目
- 有清晰的一手来源可以追溯
- 能解释“为什么这件事值得今天记下来”
- 如果属于 AI 圈博主，必须标明它是 `信息线索`、`观点判断`、`方法论` 还是 `实践复盘`，并解释为什么值得今天记录
- 如果属于 AI 研究前沿，必须提供原文链接，并说明它可能影响什么技术路线或未来判断
- 如果属于 AI 外围情报，必须能够明确解释它会如何反作用于 AI 主线，而不是单纯的泛科技资讯
