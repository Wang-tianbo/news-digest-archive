## AI 研究前沿

### Proactive Memory Agent：把长任务 agent 的“行为状态衰减”显式建模

- 类型：论文
- 日期：2026-07-10 01:26 Asia/Shanghai（补充范围）
- 研究问题：长任务中，任务要求、环境事实、失败诊断、未完成子目标和历史尝试会被长轨迹淹没或挤出上下文，导致 action agent 在关键时刻用不到相关状态。
- 核心思路：论文 [Remember When It Matters: Proactive Memory Agent for Long-Horizon Agents](https://arxiv.org/abs/2607.08716) 提出一个并行运行的 memory agent，在不改 action agent 的前提下维护结构化 memory bank，并决定何时注入 memory-grounded reminder 或保持沉默。作者称其在 Terminal-Bench 2.0 和 `tau^2`-Bench 上分别带来 pass@1 提升。
- 为什么可能影响未来：Codex、Claude Code、Qwen Code、Copilot CLI 和 ChatGPT Work 都在走向长任务。长期任务失败常常不是模型不会做，而是状态、约束和中间诊断在轨迹里失活。主动记忆比简单 RAG 更接近 agent runtime 需要解决的问题。
- 局限 / 待验证点：这是早期论文，本次未验证代码、数据和外部复现；不同任务中主动 reminder 也可能引入干扰或过拟合 benchmark。
- 研究成熟度：早期论文。
- 可复现状态：原文公开；本次未确认作者代码仓库。
- 原文链接：[arXiv 2607.08716](https://arxiv.org/abs/2607.08716)
- 权威解读：暂无。
- 我的判断：这条比单纯“更长上下文”更值得跟踪，因为它把 agent 失败归因从上下文长度转向状态管理策略。后续应观察是否被主流 agent harness 或 coding-agent 产品吸收。
