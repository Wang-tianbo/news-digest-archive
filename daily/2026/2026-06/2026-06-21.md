## 今日最重要的 3 条更新

### 1. Qwen Code `0.18.4` 发布，集中强化权限、hooks、loop、workflow、Web Shell 与边界校验

- 发生了什么：`QwenLM/qwen-code` 于 `2026-06-20 17:37` Asia/Shanghai 发布 [v0.18.4](https://github.com/QwenLM/qwen-code/releases/tag/v0.18.4)，随后于 `2026-06-21 08:50` Asia/Shanghai 发布 [v0.18.3-nightly.20260621.6b2f800ab](https://github.com/QwenLM/qwen-code/releases/tag/v0.18.3-nightly.20260621.6b2f800ab)。`0.18.4` 包含 ACP permission timeout 可配置、daemon idle detection for `GET /health?deep=true`、hook system 传入原始 `toolCallId`、per-turn tool-call circuit breaker、workflow tool token budget、prompt-only `/loop`、second-resolution wakeup engine、token usage visibility、`qwen serve` Web Shell UI、extension management、QQ Bot adapter，以及大量 MCP、OAuth、cron、sandbox、URL scheme、terminal sequence、session / token / path boundary 修复。后续 nightly 又继续补 plan mode opt-in、workspace boundary、LSP socket port、tool concurrency env、NO_PROXY port、computer-use integer、Requesty provider 等校验。
- 为什么重要：这是一条中国侧 AI 编程代理的高价值工程信号。Qwen Code 正在把 agent 长任务、服务化、外部通道、扩展系统和权限边界一起推进；这类更新比单一模型入口更能决定工具能否被团队持续使用。
- 来源：
  [Qwen Code Release - v0.18.4](https://github.com/QwenLM/qwen-code/releases/tag/v0.18.4)
  [Qwen Code Nightly - v0.18.3-nightly.20260621.6b2f800ab](https://github.com/QwenLM/qwen-code/releases/tag/v0.18.3-nightly.20260621.6b2f800ab)

### 2. Claude Code `2.1.185` 调整 API 静默重试提示，降低误判“无响应”的交互噪声

- 发生了什么：`anthropics/claude-code` 于 `2026-06-21 04:59` Asia/Shanghai 发布 [v2.1.185](https://github.com/anthropics/claude-code/releases/tag/v2.1.185)。Release notes 显示，stream-stall hint 文案从 “No response from API · Retrying in …” 改为 “Waiting for API response · will retry in …”，触发时间也从 10 秒静默改为 20 秒静默。
- 为什么重要：这是小版本，但方向明确。Claude Code 前几日刚强化 auto mode destructive command 阻断，本期则处理长任务等待过程中的用户感知；对 agent 工具来说，可靠性不只包括执行正确，也包括不要把正常延迟误包装成故障。
- 来源：[Claude Code Release - v2.1.185](https://github.com/anthropics/claude-code/releases/tag/v2.1.185)

### 3. llama.cpp 连续修补 GLM-5.2 加载、CORS proxy auth、AMX 性能与 JSON schema grammar

- 发生了什么：`ggml-org/llama.cpp` 在本窗口发布多条构建：[b9735](https://github.com/ggml-org/llama.cpp/releases/tag/b9735) 优化 AMX 量化路径，并在给出的 Intel Xeon 8488C / Qwen3.5 0.8B 样例中让部分 prompt processing 吞吐提升约 `1.4x`；[b9736](https://github.com/ggml-org/llama.cpp/releases/tag/b9736) 将 GLM_DSA loader 的 DSA indexer tensors 标记为 optional，使 GLM-5.2 GGUF 在部分 layer 省略 indexer 时仍可加载；[b9738](https://github.com/ggml-org/llama.cpp/releases/tag/b9738) 避免 CORS proxy 转发 auth headers；[b9743](https://github.com/ggml-org/llama.cpp/releases/tag/b9743) 对齐 JSON schema-to-grammar spacing rules 与 parsers。
- 为什么重要：llama.cpp 是本地 / 私有推理和很多 agent backend 的基础设施。GLM-5.2、DeepSeek-V3.2、CORS proxy、structured output grammar 这些看似底层的修补，会直接影响本地模型在 agent 工具调用、浏览器 UI、schema 输出和私有部署中的稳定性与安全边界。
