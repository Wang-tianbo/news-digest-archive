### 1. Anthropic 发布 `Claude Code v2.1.152` 与 `v2.1.153`

- 发生了什么：`anthropics/claude-code` 于 `2026-05-27 09:30` 和 `2026-05-28 08:52` Asia/Shanghai 分别发布 [v2.1.152](https://github.com/anthropics/claude-code/releases/tag/v2.1.152) 与 [v2.1.153](https://github.com/anthropics/claude-code/releases/tag/v2.1.153)。关键变化包括 `/code-review --fix`、skills / slash commands 的 `disallowed-tools`、`/reload-skills`、`SessionStart` reloadSkills、`MessageDisplay` hook、plugin suggestion marketplaces、fallback model、MCP 鉴权提示合并、`/doctor` 更新尝试结果、后台 agents 权限和多项 MCP / daemon / memory 修复。
- 为什么重要：这批改动把 Claude Code 的重点从“强模型终端体验”继续推向 `插件生态 + 技能治理 + 后台任务 + 企业 MCP 策略 + 诊断恢复`。这正是团队长期使用时会反复碰到的层面。
