#### 1. Qwen Code nightly 把持久化、路由和跨 session 控制面继续做深

- 事实：Qwen Code `v0.23.3-nightly.20260912.54aa66834b` 于 2026-09-12 22:03 UTC 发布。release notes 包含 cross-session messaging peer endpoint、按 turn 或 active-time budget 停止 Goal、重启后恢复 channels、持久化 MCP 配置、scheduled runs 按 model 路由、继续 interrupted sessions、保存取消响应和耗时、Codex executor / native agent builtins，以及为 hooks 增加 `permission_mode`、`agent_id`、`prompt_id` 等字段。
- 重要性：这不是单一功能更新，而是把外部接入、调度、恢复、子 agent 和治理元数据放进同一运行时。
- 我的判断：这是本期最强的中国 / 开源 coding-agent 信号，但 nightly 状态意味着认证、session ownership、跨进程审计和升级兼容性仍需验证。
- 来源：[Qwen Code nightly release](https://github.com/QwenLM/qwen-code/releases/tag/v0.23.3-nightly.20260912.54aa66834b)

#### 2. Gemini CLI 修复间接 prompt injection 并收紧文件系统边界

- 事实：Gemini CLI `v0.61.0-nightly.20260912.g9c1b0a610` 于 2026-09-12 01:25 UTC 发布，修复通过构建文件修改和不可信 flags 触发的间接 prompt injection，并加强 filesystem boundaries 与 runtime state isolation。
- 重要性：coding agent 的攻击面不只在模型输出，也在构建文件、命令参数和本地状态之间的信任传递。
- 我的判断：这类修复比泛泛的“安全增强”更值得跟踪，因为它直接对应 agent 执行面；下一步要看修复是否覆盖插件、MCP 和外部工作区入口。
- 来源：[Gemini CLI nightly release](https://github.com/google-gemini/gemini-cli/releases/tag/v0.61.0-nightly.20260912.g9c1b0a610)

#### 3. Claude Code 修复长运行 session 中的只读 Git 权限回归

- 事实：Claude Code `v2.1.270` 于 2026-09-12 19:45 UTC 发布，修复长时间运行的 session 中，通过 Bash 执行只读 Git 命令却意外请求权限的问题；release notes 标明这是 `v2.1.269` 引入的回归。
- 重要性：对后台或长运行 agent 而言，权限提示的稳定性会直接决定任务能否无人值守地继续。
- 我的判断：这是窄范围修复，但它比新增一个表面功能更能反映 agent runtime 的真实成熟度：权限状态必须跨 turn 保持一致，并且回归要能快速定位。
- 来源：[Claude Code v2.1.270 release](https://github.com/anthropics/claude-code/releases/tag/v2.1.270)

#### 4. Vercel workflow-harness 保持快速迭代，但本次仅是依赖更新

### MindTopo：空间推理分数不能替代闭环规划能力

- 类型：benchmark / 论文
- 研究问题：基础模型是否能在拓扑空间中进行推理和闭环规划。
- 核心思路：benchmark 包含 11,030 个实例、13 类任务，比较推理和规划表现，并审计生成 rollout 是否保留环境动力学与拓扑关系。
- 为什么可能影响未来：它提醒 agent 评测要区分静态 reasoning 与真实 closed-loop planning，这与 coding agent 的工具执行、恢复和状态一致性同构。
- 局限 / 待验证点：结果来自单一 benchmark，不能直接外推到所有 agent 或真实生产环境。
- 研究成熟度：早期 benchmark
- 可复现状态：作者公开论文与任务定义，未独立验证
- 原文链接：[arXiv:2609.11900](https://arxiv.org/abs/2609.11900)
- 权威解读：暂无
- 我的判断：本期不把它当作能力提升证据，而把它作为评测设计的反例：reasoning 成绩高不等于执行循环可靠。
