### 1. GitHub 在 2026-05-18 将 Copilot CLI 远程控制扩展到移动端、Web、VS Code、JetBrains，并宣布 GA

- 发生了什么：GitHub 于 2026-05-18 发布 [Remote control for Copilot CLI sessions now generally available on mobile, web, and VS Code](https://github.blog/changelog/2026-05-18-remote-control-for-copilot-cli-sessions-now-generally-available-on-mobile-web-and-vs-code/)。官方同时确认远程控制已支持 `GitHub Mobile`、`github.com`、`VS Code`、`JetBrains`，并且不再局限于 GitHub 仓库，非 GitHub 仓库和普通目录也可接入。
- 为什么重要：这把 CLI agent 从“只能守在本机终端前”推进到“任务在本地跑，但控制面可跨设备移动”。对长任务来说，权限批准、补充指令、计划确认和状态查看不再被办公地点绑定，真实工作流价值明显上升。
