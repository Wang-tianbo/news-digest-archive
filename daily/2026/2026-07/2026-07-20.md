#### 1. Claude Code `v2.1.215`：`/verify` 与 `/code-review` 改为显式调用

- 发生了什么：Anthropic 在 2026-07-19 10:56 Asia/Shanghai 发布 [Claude Code `v2.1.215`](https://github.com/anthropics/claude-code/releases/tag/v2.1.215)，变更点是 Claude 不再自行运行 `/verify` 和 `/code-review` skills，用户需要在希望执行时显式调用。

## AI 研究前沿

### CAISI 对 GLM-5.2 的能力与安全评估

- 类型：eval / 实验室动向
- 研究问题：开权重前沿模型 GLM-5.2 的整体能力、网络能力、安全防护和 agent hijacking / jailbreak 鲁棒性如何与中美参考模型相比。
- 核心思路：CAISI 用一组能力和安全评估，把 GLM-5.2 放在能力增长曲线、网络能力、安全 safeguard、bio 问题阻断和自托管开权重风险等维度下比较。
- 为什么可能影响未来：如果开权重模型接近闭源前沿能力，模型治理、企业部署、红队评估和出口 / 安全政策都会更关注“可下载权重 + 高网络能力”的组合风险。
- 局限 / 待验证点：公开页面提供的是评估摘要；具体任务集、样本、置信区间和模型调用设置需要结合完整 assessment 才能复核。
- 研究成熟度：官方评估摘要，已完成第三方机构评估。
- 可复现状态：摘要可复查，完整复现实验待进一步材料。
- 原文链接：[NIST / CAISI - CAISI Assessment of Z.ai's GLM-5.2](https://www.nist.gov/news-events/news/2026/07/caisi-assessment-zais-glm-52)
- 权威解读：暂无比原始评估更优的一手解读。
- 我的判断：GLM-5.2 的真正信号不是“某个开源模型又强了”，而是开权重模型开始进入政府级能力 / 安全评估的主舞台。
