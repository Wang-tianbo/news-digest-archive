### 1. GitHub 在 `2026-06-02` 集中发布 Copilot 平台化能力：SDK GA、sandbox、agent apps、automations、Memory 与 Chronicle

- 发生了什么：GitHub 于 `2026-06-02` 发布一组 Copilot 官方更新，包括 [Copilot SDK is now generally available](https://github.blog/changelog/2026-06-02-copilot-sdk-is-now-generally-available)、[Cloud and local sandboxes for GitHub Copilot now in public preview](https://github.blog/changelog/2026-06-02-cloud-and-local-sandboxes-for-github-copilot-now-in-public-preview)、[Extend GitHub with agent apps](https://github.blog/changelog/2026-06-02-extend-github-with-agent-apps)、[Schedule and automate tasks with Copilot cloud agent](https://github.blog/changelog/2026-06-02-schedule-and-automate-tasks-with-copilot-cloud-agent)、[Gain insights across your agent sessions with /chronicle](https://github.blog/changelog/2026-06-02-gain-insights-across-your-agent-sessions-with-chronicle)、[Copilot Memory supports user preferences for Business, Enterprise](https://github.blog/changelog/2026-06-02-copilot-memory-supports-user-preferences-for-business-enterprise)。
- 为什么重要：这是典型的平台化组合。SDK 让外部应用接入 Copilot agent runtime；sandbox 给 tool execution 提供隔离层；agent apps 把第三方 agent 放进 GitHub Marketplace 和 GitHub workflow；automations 让 cloud agent 能按时间或仓库事件自动运行；Chronicle / Memory 把跨会话历史、偏好和洞察变成可复用资产。GitHub 正在把 Copilot 从 IDE 功能推进为 `agent operating layer`。

### 3. Claude Code 连续两版强化后台 agent、安全写入和组织遥测

- 发生了什么：`anthropics/claude-code` 在本窗口内发布 [v2.1.160](https://github.com/anthropics/claude-code/releases/tag/v2.1.160) 与 [v2.1.161](https://github.com/anthropics/claude-code/releases/tag/v2.1.161)。`v2.1.160` 增加对 shell startup files、Git config、构建工具配置等潜在执行入口的写入提示，并修复 background sessions 恢复、overnight retire、cold-start socket、Windows / WSL clipboard、CJK IME、终端同步输出等问题。`v2.1.161` 增加 `OTEL_RESOURCE_ATTRIBUTES` 指标标签、`claude agents` fan-out 进度、并行工具调用失败隔离、Linux clipboard 改进，并修复 managed settings、stdout 污染、MCP secret 打印、worktree isolation、daemon stale model 等问题。
- 为什么重要：Claude Code 的 release note 正在把后台 agent 当作真实运行面处理，而不只是一个附属模式。安全写入提示、遥测标签、并行工具隔离和后台恢复，都是组织级使用 agent 时很快会遇到的基础问题。
