## 本周主线

本周真正持续出现的主线，是 AI 编程代理继续从“能写代码”变成“能被组织长期托管的运行时”。GitHub、Anthropic、OpenAI、Qwen、Google、Cursor、Kimi Code 在不同入口上反复补同一组能力：权限、审批、沙箱、远控、后台会话、subagent、review contract、tool-call 错误语义、成本和模型策略。

第二条主线是 MCP / Skill / plugin 不再只是扩展入口，而是进入治理问题。Copilot Customize GA、Qwen-MM-Plugins、Codex MCP result interception、Gemini restricted-mode MCP filtering、Pydantic AI / Vercel AI SDK 的 tool schema 与 durable execution 更新，共同说明“工具如何被发现、授权、调用、拒绝、拦截和审计”已经成为 agent 产品本体。

第三条主线是中国开源模型竞争重新回到可部署性。Qwen3.8-Flash-Next、GLM-5.3-Flash、Tencent Hy4-preview、vLLM、SGLang、OpenCompass、Unsloth 这些信号合在一起，不是在讲参数新闻，而是在检验低激活 MoE、多模态、长上下文和 FP8 / serving recipe 是否能被真实推理栈快速接住。

第四条主线是研究侧越来越关注“过程是否可信”。SWE Refactor Bench、MCR-Bench、Prime Agent、Utility Under Attack、WikiSkill、Prefix Sliding、SPO++、VBVR-Pro 等工作都在从不同角度回答：agent 是否真的完成了任务、记忆是否被污染、技能是否能沉淀、长推理成本是否可控、视觉推理和代码审查是否可验证。

## 本周评论与判断

- 基于本周样本的判断：agent 赛道的核心竞争正在被运行时控制面重新定义。模型能力仍重要，但没有权限、会话、审查、恢复、成本、工具安全和可验证完成状态，就很难进入团队生产流程。
- GitHub 的信号最完整：Customize tab、global model policy、bot-authored PR review、review resolution reason、policy / billing、Visual Studio 组织级 agent 和 ruleset 能力，把 Copilot 接进了企业治理路径。
- Anthropic 和 OpenAI 在 Claude Code / Codex 上继续打运行时底座。Claude Code 更强调企业管理、restricted mode、hooks、Remote Control、成本和 Admin API；Codex 更强调 task graph、approval evidence、plugin / MCP、sandbox、Guardian 和 MCP result interception。
- 中国侧本周不是单点跟随。Qwen Code、Qwen-MM-Plugins、LobeHub、Dify、StaffDeck、Kimi Code，以及 Qwen / GLM / Hy4 模型发布，说明中文生态同时在追 agent runtime 和 open-weight deployability。
- 本周最应该降权的叙事，是“看一次模型发布或榜单就能判断竞争格局”。更好的观察单元已经变成：模型能否被推理栈接住，agent 能否被组织治理，任务结果能否被外部验证。

## 本周判断复盘

### 上周判断哪些被验证

- `agent_runtime_governance` 被强验证。权限、沙箱、远控、后台会话、审查、成本、workflow opt-in 和 subagent 边界在七篇日报中持续出现。
- `enterprise_agent_control_plane` 被继续验证。Copilot、Claude Code、Codex、Cursor、Qwen Code 都在把 agent 放进组织策略、计费、审计、review 和协作入口。
- `china_open_agent_runtime` 被强化。Qwen Code、StaffDeck、LobeHub、Dify、Kimi Code 不再只是客户端更新，而是在补任务、通道、review、handoff、sandbox 和远控。
- `model_routing_control_plane` 被拓宽。除了 OpenAI 区域处理和缓存，Copilot 模型策略、Pydantic / Vercel provider adapter、Neurometric tool-calling SLM、OpenAI-Cursor 模型供应事件，都把路由、供应和成本拉到主线。

### 上周判断哪些被修正

- `agent_harness` 需要拆细。本周更准确的分层是：runtime governance、MCP / Skill governance、verification / acceptance evidence、persistent memory、planner / executor split。
- `open_weight_models` 不能只写“开源权重升温”。本周更关键的是 deployability：vLLM / SGLang / TokenSpeed / OpenCompass / Unsloth 是否快速适配，才决定 Qwen、GLM、Hy4 的真实影响。
- `AI 圈博主` 的权重需要更偏方法和证据。本周高价值社区样本不是情绪判断，而是 Simon Willison 的 auto mode 安全复盘、Hy4 chat template 观察、DeepSeek Harness 现场排障、OpenContext / Jeffy Loop 的完成证明和记忆线索。

### 本周新增判断

- `agent_verification` 值得升格为长期议题。Copilot bot PR review、LobeHub acceptance evidence、SWE Refactor Bench、MCR-Bench、Jeffy Loop 都在说同一件事：agent 自称完成不够，必须有可审计的外部证明。
- `mcp_security` 应该独立跟踪。Gemini MCP OAuth SSRF 修复、restricted-mode MCP filtering、Codex MCP result interception、Pydantic safe download 都说明工具协议安全已经进入默认运行时问题。
- `model_supply_chain` 值得观察。OpenAI-Cursor 模型合同事件如果后续被继续证实或扩散，会让 coding agent 厂商更重视多模型冗余、自有模型策略和企业 SLA。

## 本周三大雷达

### AI 新闻

- GitHub Copilot 是本周最强的企业控制面样本。Customize tab GA 把 MCP / plugins / skills / canvases 放到统一入口；global model policy GA 和 policy / billing 调整把模型使用、座位、默认 review effort 推向组织策略；bot-authored PR review 与 resolution reason 则开始形成 agent 产物审查闭环。
- Claude Code 持续补 agent ops。v2.1.243 到 v2.1.251 反复出现组织托管定价、modelPicker、prompt cache TTL、Console keyless sign-in、subagent 可观测性、restricted mode、hooks、Remote Control、Admin API、成本优化和安全修复。
- Codex 从 0.150 alpha 进入 0.150 stable，再到 0.151.0，重点落在 task mention、任务 TUI、approval evidence、credential broker、thread history、MCP OAuth、plugin catalog、MCP result interception、sandbox 和 Guardian stale classification。
- Qwen Code / Kimi Code / StaffDeck / LobeHub / Dify 组成中文 agent runtime 线。高频信号包括 WebShell、review contract、workflow opt-in、persistent tasks、DingTalk / Feishu channel、Computer Use skill、agent sandbox、skill management、trace snapshot 和 goal attribution。
- Qwen3.8-Flash-Next、GLM-5.3-Flash、Hy4-preview 把中国模型主线推向低激活 MoE、多模态、长上下文和开放权重，但本周判断仍应停留在“强待验证信号”，不是“部署优势已成立”。

### AI 圈博主

- 中文来源的重复线索主要来自 LobeHub、Qwen Code、StaffDeck、Dify 和中文开发者长文。它们共同体现的不是“哪个客户端更新更快”，而是中文 AI workspace 正在把任务持久化、review、handoff、channel binding、sandbox、skill、trace 和验收证据做成可复查运行时。
- 英文来源的高价值样本更偏方法论和工程证据。Simon Willison 对 Claude Code auto mode 的安全复盘，把问题从“能否阻止危险命令”推进到“门控策略是否会阻断补救路径”；对 Hy4-preview 的观察则提示 reasoning effort 已通过模板暴露给开发者。
- Vercel AI SDK、Pydantic AI、LangChain、DeepSeek Harness discussion、Braintrust plugin、OpenContext、Jeffy Loop、Neurometric 等样本说明，社区正在围绕 tool-call schema、HITL rejection、durable execution、observability、persistent memory、completion proof 和 planner / executor cost split 建立共同语汇。
- 这些观点和线索都只能作为 clue / opinion sample。事实确认仍以官方 changelog、release、论文原文、模型卡和开源仓库为准。

### AI 研究前沿

- coding-agent 评测是最强研究线。SWE Refactor Bench 把整仓迁移拆成 migration audit、behavioral tests 和 agentic verification；MCR-Bench 把真实代码审查流程纳入 benchmark。它们共同削弱了“过现有测试就算完成”的旧评价口径。
- agent 记忆和技能演化进入风险与资产双重视角。Utility Under Attack 提醒 persistent memory 会带来长期污染面；AUSO、Prime Agent、WikiSkill 则从 skill optimization、persistent harness、knowledge base 角度说明经验如何被保留、复用和进化。
- agentic RL 与异步长任务开始对应产品现实。SPO++、SWE-Prime 关注更少轨迹、异步 stream-aligned optimization 和生产式长工具调用，和本周产品侧的 background session、subagent、workflow、durable execution 同频。
- 推理成本和多模态可验证性也在升温。Prefix Sliding 指向长上下文 / test-time scaling 成本，VBVR-Pro 指向可验证视觉推理，OpenCompass v0.5.4 则提供多模态、多轮和 gateway 评测框架更新。
- AgentHands、Instruct-to-Act、Model Hardware Standard 等信号把 agent 从软件工具扩到空间化交互、具身控制和物理设备操作，但本周它们是外围增强线，不是 coding-agent 主线。

## 重点主题追踪

### 核心赛道

- 中美大模型：美国侧本周主要是平台与供应关系；中国侧主要是 Qwen3.8-Flash-Next、GLM-5.3-Flash、Hy4-preview 的开放权重和部署配方。短期重点不是参数，而是推理栈支持、质量复现和企业可用性。
- AI 编程代理：最强主线。Copilot、Claude Code、Codex、Qwen Code、Gemini CLI、Cursor、Kimi Code 都在向组织级运行时靠拢。
- 开源与基础设施：vLLM、SGLang、OpenCompass、Pydantic AI、Vercel AI SDK、LangChain、OpenContext、Jeffy Loop 共同构成 agent 和模型部署的基础设施层。
- 研究前沿：评测、记忆、安全、技能、异步 RL、长推理成本和可验证视觉推理，是本周最值得延续的方向。

### AI 外围情报观察

- 本周外围变量有三类确实反作用于 AI 主线：企业代码治理、物理设备操作标准、模型供应合同稳定性。
- GitHub ruleset insights、path exceptions、Copilot policy / billing 和 bot PR review 会决定 agent 写代码后如何进入真实组织控制链。
- Anthropic Model Hardware Standard 虽然仍是 research preview，但把 agent governance 从软件工具调用扩到实验室、制造和实体设备。
- OpenAI-Cursor 模型供应信号仍需后续确认细节，但它已经足以提示：coding agent 厂商的模型访问不是背景条件，而可能成为产品连续性的关键风险。

### GitHub 热门项目

- `QwenLM/Qwen-MM-Plugins`：把多模态能力包装成可跨 Claude Code、Codex、Qwen Code、Gemini CLI 复用的 Skill / MCP 插件，值得作为 `mcp_skill_ecosystem` 样本跟踪。
- `sgl-project/sglang` 与 `vllm-project/vllm`：本周分别通过 SGLang v0.5.18 和 vLLM v0.28.0 显示开源 serving stack 对 Qwen、GLM、Kimi、DeepSeek、MiniMax 等模型的适配速度。
- `OpenBMB/StaffDeck`：v0.5.0 / v0.5.1 连续补 harness、handoff、channel binding、skill events 和后台清理，是中文企业 agent workflow 的代表样本。
- `lenamonj/jeffy-loop` 与 `slxca/opencontext`：项目仍早期，但“完成证明”和“项目本地持久记忆”与本周研究和产品信号高度同频。

- 当前状态：升温
- 下周观察点：主流 agent 是否把 acceptance evidence、review witness、test generation 和 audit trail 变成公开接口。

### open_weight_deployability

- 本周新增事实：Qwen3.8-Flash-Next、GLM-5.3-Flash、Hy4-preview 开放权重或模型卡；vLLM、SGLang、OpenCompass、Unsloth 和社区论坛开始快速响应。

- 当前状态：待确认
- 下周观察点：vLLM / SGLang / llama.cpp / OpenCompass 是否给出稳定适配、性能和可复现评测。

### persistent_agent_memory

- 本周新增事实：Utility Under Attack 给出 memory poisoning 风险；WikiSkill、Prime Agent、OpenContext、LobeHub trace / goal 线索都在推进持久经验和项目记忆。
- 本周判断：记忆会同时提高长期任务能力和长期污染风险，必须和 provenance、审计、占用上限、清理路径一起设计。
- 当前状态：升温
- 下周观察点：是否出现产品级记忆写入审计、项目本地记忆规范和错误记忆清理机制。
