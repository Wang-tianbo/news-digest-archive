### 1. SQD：subquadratic attention 可能改变推理服务拆分方式

- 类型：论文
- 研究问题：当前 disaggregated serving 多围绕 dense attention 做决策，但 subquadratic attention LLM 的 memory footprint 和 arithmetic intensity 不同，是否应按注意力结构重新拆分推理。
- 核心思路：论文提出 SQD，把 decode 按 quadratic / subquadratic attention 拆分，而不是只按 operator type 拆分，并分析 sparse、linear、sliding-window attention 的不同服务路径。
- 为什么可能影响未来：如果模型架构继续采用 subquadratic attention，provider route 和 inference stack 的能力差异会更明显，企业评测需要把 serving architecture 纳入模型选择。
- 局限 / 待验证点：结果来自系统代理和分析模型，仍需真实生产 serving、不同模型和不同硬件拓扑下的独立验证。
- 研究成熟度：早期论文
- 可复现状态：论文公开，未确认第三方复现
- 原文链接：[arXiv:2609.13134](https://arxiv.org/abs/2609.13134)
- 权威解读：暂无
- 我的判断：它和 Copilot auto routing、OpenRouter provider 差异、DeepSeek route 讨论属于同一条长期线索：模型能力越来越取决于模型和服务系统的组合。

### 2. Embodied-BenchForge：benchmark 构造也需要 artifact dependency 和局部修复

- 类型：论文 / benchmark
- 研究问题：多步骤 embodied benchmark 构造中，中间 artifact 的局部错误会沿依赖链传播，如何用 agentic workflow 构造、验证和修复 benchmark。
- 核心思路：论文提出 Closed-Loop Benchmark Synthesis、Skill-Orchestrated Artifact Synthesis、artifact dependency graph、Requirement-Guided Verification and Repair，并在多个 embodied benchmark 中测试。
- 为什么可能影响未来：这与软件 agent 的 workflow、checkpoint、Goal、hook provenance 问题同构：长期任务需要把中间产物、依赖和修复范围显式化。
- 局限 / 待验证点：主要面向 embodied benchmark，不能直接外推到所有 coding agent 或企业工作流。
- 研究成熟度：早期论文 / benchmark
- 可复现状态：论文公开，未确认第三方复现
- 原文链接：[arXiv:2609.13082](https://arxiv.org/abs/2609.13082)
- 权威解读：暂无
- 我的判断：它最值得借鉴的是 dependency graph 和局部回滚语义；这比“让 agent 自动造 benchmark”这个标题更重要。
