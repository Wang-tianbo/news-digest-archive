## 本周评论与判断

基于本周已存档样本的判断，AI 编程代理的竞争焦点正在从“谁接入最新模型”转向“谁能把模型接入可治理的工作系统”。Sonnet 5 的强信号不只在模型能力，而在它当天进入 Claude Code 默认项、Copilot / Cline provider 和企业可用 surface；这说明模型如果不能快速进入 IDE、CLI、组织策略和预算系统，发布影响会被显著折损。

基于本周样本的判断，GitHub 正在把 Copilot 变成企业 agent control plane。`managed-settings.json`、session streaming、Actions token、usage metrics、AI credit pools、GitHub Models 退役和 Gemini 模型生命周期管理，共同说明 Copilot 的竞争点已经覆盖模型路由、审计、成本、CI 自动化和产品线收敛。

基于本周样本的判断，Claude Code 与 Qwen Code 的共同方向是“长期任务的运行时治理”。Claude Code 的 browser control、background draft PR、partial work、Manual permission 和 session recovery，Qwen Code 的 daemon / Web Shell / PR gate / session export / leader approval，都是为真实团队任务补控制面，而不是只改善单次生成。

基于本周样本的判断，工具调用可靠性会成为下一阶段显性指标。Cline 对 malformed tool calls 做容错，Armin Ronacher / Simon Willison 记录强模型也可能破坏嵌套 schema，Copilot CLI 引入运行中 MCP 管理和 LLM judge 自动放行，Pydantic AI 做 agentic evaluators。后续应该更关注 schema adherence、tool-call repair、权限自动批准和审计，而不是只看模型 benchmark。

基于本周样本的判断，中国侧仍应克制表述：Qwen Code 明显升温，但不能外推为中国所有模型公司已形成公开 agent runtime 赛道。DeepSeek DeepSpec、Qwen Code、百度千帆 Claude Code 接入文档是有价值线索；Z Code / GLM、火山方舟、Kimi、MiniMax 等本周缺少同等级严格窗口一手发布。
