## 今日评论与判断

基于本期已确认事实样本的判断，Hy3 值得记录，但还不能直接等同于“腾讯混元在 agent 模型上完成了一次跃迁”。官方仓库和模型卡给出了模型规模、上下文长度、权重入口和使用说明，这是高置信事实；真正需要后续验证的是第三方 benchmark、长任务 agent 任务表现、推理成本、工具调用稳定性和生态适配。

基于本期样本的判断，AI 编程代理正在进入“团队控制面”竞争。Claude Code 的 workflow OTel attributes、Qwen Code 的 scheduled tasks / session groups / PreToolUse `ask`、Copilot CLI 的 MCP OAuth callback flow、OpenAI Agents SDK 的日志脱敏和 strict schema validation，都不是单次 coding demo 能体现的能力，而是团队把 agent 放进真实开发流程时会遇到的治理、审计和恢复问题。

基于本期样本的判断，OpenAI Codex alpha 的信号仍偏工程内部，但方向值得跟踪。`safety_buffering` 中读取 `retry_model`、thread start 时重新发出 exec-policy warnings、取消 review 后释放 MCP startup busy 状态，这些都说明 Codex 类产品的真实难点正在从“能不能生成代码”转向“长会话、多插件、多策略、多模型回退时是否可解释”。

基于本期样本的判断，社区信号和研究前沿都在提醒同一件事：agent 的能力边界要靠可复查样本来校准。Simon Willison 记录 Hy3 是一个发现线索；科学空间的训练调度文章、Vercel AI SDK 的 signed tool approval metadata、Ethan Mollick 对 chatbots 形态的反思和 MIPU 的视觉提示学习论文，分别从工程、产品形态和研究评测层面补足了同一条主线。

## AI 研究前沿

### The Mirage of Imagination：用视觉提示学习检验多模态模型的想象边界

- 类型：论文
- 研究问题：多模态大模型是否真的能从少量视觉提示中学习抽象规则，还是主要依赖表面模式匹配。
- 核心思路：论文 [The Mirage of Imagination: Evaluating Visual Prompt Learning in Multimodal LLMs](https://arxiv.org/abs/2606.29526) 构造 MIPU benchmark，用视觉 prompt learning 任务考察模型在多模态输入中推断规则、迁移规则和避免幻觉的能力；项目页提供 [MIPU benchmark](https://anitaleungxx.github.io/MIPU/)。
- 为什么可能影响未来：如果多模态 agent 要处理屏幕、图像、UI 和真实世界任务，模型能否从视觉上下文中学习规则，会直接影响 computer use、GUI automation、视觉问答和具身 agent 的能力边界。
- 局限 / 待验证点：本期仅保留论文与项目页信号，尚未看到主流实验室或第三方大规模复现；是否能预测真实 GUI agent 表现还需要后续验证。
- 研究成熟度：早期论文 / benchmark。
- 可复现状态：论文与项目页公开；是否完整开源需后续核验。
- 原文链接：[arXiv 2606.29526](https://arxiv.org/abs/2606.29526)、[MIPU project page](https://anitaleungxx.github.io/MIPU/)
