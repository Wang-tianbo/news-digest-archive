## 今日评论与判断

基于本期确认事实样本，我的判断是：agent 产品的主战场正在从“单点智能”转向“系统可控”。Grok 4.5 进入 Copilot 说明模型选择会继续多供应商化，但 Copilot app usage metrics、Business / Enterprise 默认关闭 Grok 策略、Dify sandbox proxy、Qwen review write contract、Gemini workspace trust，才是企业能否真正采用 agent 的关键。

第二个判断是，MCP 的 2026-07-28 规范比普通工具 release 更重要。stateless protocol core 和 cacheable list results 会影响服务部署、连接恢复、网关路由和多租户托管；MRTR 与 authorization hardening 则把“工具调用协议”推向真实 agent runtime 需要的控制面。

第三个判断是，AI for science 和 AI security research 正在变成同一条线的两面：模型可以帮助科研人员更快探索科学计算，也可以以机器速度搜索 cryptographic / infrastructure 弱点。未来一段时间，真正值得跟踪的是“agent 如何被授权、限制、记录、复核”，而不是只看它解决了多少题。

第四个判断是，中文工程生态今天没有基础模型级发布，但 Qwen Code、Dify、Chatbox 的更新都指向同一个趋势：国产 AI 工具正在把 agent 做成本地 / Web / workflow / channel / sandbox 的复合工作台。短期版本噪声很大，中期看点是安全边界和审计能力能否跟上功能扩张。

### Anthropic Claude Mythos：发现 HAWK 和 reduced AES 的 cryptanalysis 改进

- 类型：研究博客 / benchmark / 开源实现
- 研究问题：frontier AI agent 是否能帮助发现 cryptographic algorithm 层面的数学弱点，而不只是找实现 bug。
- 核心思路：Anthropic 介绍 Claude Mythos Preview 辅助发现两类 cryptanalysis 进展：一是改进 HAWK post-quantum digital signature scheme 的 key recovery attack；二是改进 round-reduced AES 攻击。Anthropic 同时发布 CryptanalysisBench，并提供研究 demo 仓库。
- 为什么可能影响未来：这把 AI 安全研究推进到更硬的领域：如果模型可以以长时间 autonomous / scaffolded 方式探索 cryptography，未来算法设计、标准化和 red-team 都要考虑 AI agent 参与。
- 局限 / 待验证点：Anthropic 明确说明这些结果不影响当前生产系统：HAWK 是候选签名方案，AES 结果针对 reduced version 而非完整 AES；每个结果约 10 万美元 API 成本，也说明当前仍是昂贵研究能力。
- 研究成熟度：实验室研究 / 已协调披露。
- 可复现状态：有研究博客、论文方向和 demo 仓库；第三方系统复现仍需观察。
- 原文链接：[Anthropic Research - Discovering cryptographic weaknesses with Claude](https://www.anthropic.com/research/discovering-cryptographic-weaknesses)、[anthropics/cryptography-research-demo](https://github.com/anthropics/cryptography-research-demo)
- 权威解读：[Simon Willison - Discovering cryptographic weaknesses with Claude](https://simonwillison.net/2026/Jul/28/discovering-cryptographic-weaknesses-with-claude/#atom-everything)
- 我的判断：这是本期最强研究信号。它不是“AI 已经能替代密码学家”，而是说明 frontier agent 可以成为昂贵但有价值的研究搜索器；对应的治理问题会比普通 coding agent 更硬。
