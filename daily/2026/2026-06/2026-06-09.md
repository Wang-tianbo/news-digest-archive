## 今日最重要的 5 条更新

### 1. Codex `0.138.0` 稳定版发布，CLI 到 Desktop、auth、插件和目标工作流进入正式收拢

- 发生了什么：`openai/codex` 于 `2026-06-09 07:00` Asia/Shanghai 发布 [rust-v0.138.0](https://github.com/openai/codex/releases/tag/rust-v0.138.0)。Release notes 显示 `/app` 可将当前 CLI thread 交给 Codex Desktop；本地图像附件和独立图像生成会把保存路径暴露给模型；app-server 可读取账号 token usage；Codex auth 支持 v2 personal access tokens；插件 add/remove、marketplace、list/detail 增加更完整 JSON 输出；目标工作流、TUI、启动、远程 / symlink workspace 指令加载和大 MCP/Ollama stream 处理也有修复。
- 为什么重要：这把前几天 `0.138` alpha 的弱信号变成稳定版事实。Codex 正在把“终端代理”往更完整的本地/桌面/插件/组织自动化 runtime 推，而不是只做命令行补丁。
- 来源：
  [Codex Release - rust-v0.138.0](https://github.com/openai/codex/releases/tag/rust-v0.138.0)
  [Codex compare - rust-v0.137.0...rust-v0.138.0](https://github.com/openai/codex/compare/rust-v0.137.0...rust-v0.138.0)

### 2. Claude Code `2.1.169` 强化 safe mode、企业 MCP policy 和后台会话可靠性

- 发生了什么：`anthropics/claude-code` 于 `2026-06-09 05:57` Asia/Shanghai 发布 [v2.1.169](https://github.com/anthropics/claude-code/releases/tag/v2.1.169)。新增 `--safe-mode` / `CLAUDE_CODE_SAFE_MODE`，可禁用 `CLAUDE.md`、plugins、skills、hooks、MCP servers 等自定义项用于排障；新增 `/cd` 命令在不中断 prompt cache 的情况下切换会话目录；新增 `disableBundledSkills`；并修复企业 managed MCP policies 在 reconnect、IDE configs、`--mcp-config`、首次安装和 remote settings 加载前未正确执行的问题。Release 还修复 remote reconnect、background agents、Windows 启动、Vertex/Foundry idle timeout、TaskCreate 可靠性等长任务边界。
- 为什么重要：这是一条强工程化信号。Claude Code 正在把“可排障、可托管、可恢复、可审计”的组织级能力补齐，而企业部署 agent 时最怕的正是自定义项污染、MCP 策略绕过、远程会话卡死和后台任务状态不可见。
- 来源：
  [Claude Code Release - v2.1.169](https://github.com/anthropics/claude-code/releases/tag/v2.1.169)
  [Claude Code compare - v2.1.168...v2.1.169](https://github.com/anthropics/claude-code/compare/v2.1.168...v2.1.169)

### 3. Claude Agent SDK Python `0.2.94` 同步 bundled Claude CLI 到 `2.1.169`

- 来源：

### 4. GitHub MCP Server `1.2.0` 对齐 stable spec，并扩展 Projects、review、commit 与 issue / PR mutation 工具

- 发生了什么：`github/github-mcp-server` 于 `2026-06-08 18:51` Asia/Shanghai 发布 [v1.2.0](https://github.com/github/github-mcp-server/releases/tag/v1.2.0)。Release notes 显示 MCP Apps 对齐 `2026-01-26` stable spec；`projects_write` 增加 `create_project` 和 `create_iteration_field`；`get_review_comments` 恢复 thread id；`get_commit` 增加 `include_patch`；issue mutation MCP tools 增加 `confidence` 参数；还补充 Zed、OpenCode、Claude Windows PowerShell 等安装文档。
- 为什么重要：GitHub MCP Server 是 agent 接管开发平台的关键基础设施。Projects、review comments、commit patch 和 issue/PR mutation 参数增强，意味着 agent 不只读仓库，还能更细地参与项目计划、代码评审和变更操作。
- 来源：
