## AI 研究前沿

### 1. SHE：让 agent safety harness 随 trajectory 失败而演化

- 类型：论文
- 研究问题：LLM agent 的安全不只取决于模型权重，还取决于管理上下文、记忆、工具、权限和运行时控制的 harness；静态 harness 难以应对新风险，也难以归因责任。
- 核心思路：论文提出 Safety Harness Evolution，把 harness 拆成 System Prompt、Rule Bank、Safety Memory、Tool Policy 四类 artifact，并用 rollout trajectory failure 做 attribution-guided evolution，再通过 safety-utility validation 选择演化后的 harness。
- 为什么可能影响未来：如果 agent 产品越来越依赖技能、MCP、远程控制和工具权限，安全边界就不能只靠模型拒答。SHE 把安全更新对象从“模型”扩展到“harness artifact”，和本期 Claude skills 加固、OpenAI sandbox acknowledgement、Copilot managed settings 高度同向。
- 局限 / 待验证点：目前是 arXiv 早期论文，实验基于 Agent-SafetyBench / AgentHarm，离真实 coding agent、浏览器 agent 和企业内网工具链仍有距离；是否能在复杂组织策略中稳定归因还需验证。
- 研究成熟度：早期论文
- 可复现状态：论文公开；本期未确认代码仓库
- 原文链接：[arXiv:2608.09885](https://arxiv.org/abs/2608.09885)
- 权威解读：暂无
- 我的判断：这是本期最贴近产品主线的研究。agent 安全会越来越像“策略和 harness 持续演化问题”，而不是单次 red-team 后冻结一套系统提示。
