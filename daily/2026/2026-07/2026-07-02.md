## 主线判断

本期最值得记住的主线是：AI coding agent 已经进入“组织控制面 + 多端执行面”的竞争阶段。Claude Code `v2.1.198` 把 Claude in Chrome 标记为 generally available，并让后台 agents 在 worktree 完成代码任务后直接 commit、push、开 draft PR；GitHub 同一窗口把 Copilot 企业 `managed-settings.json` 推到 GA，并允许企业把 `auto` 模型选择设为新会话默认值。

这不是新的基础模型 headline 日。更准确的读法是，Sonnet 5 发布后的下一步不是继续堆 benchmark，而是把模型选择、插件市场、MCP / sandbox 权限、后台任务、draft PR、浏览器控制和 session 治理做成团队可管理的默认路径。中国侧本期延续 Qwen Code 的 runtime 工程化：`0.19.4` stable 与 `20260702` nightly 把 daemon、channels、TLS、reasoning effort、leader approval、Web Shell 和 safe mode 继续向完整 agent platform 推进。
