### 1. Qwen Code 集中修 agent 长任务运行时：压缩、token、MCP、daemon 与 Computer Use

- 发生了什么：`QwenLM/qwen-code` 在 `2026-06-14 09:00` 至 `2026-06-15 09:00` Asia/Shanghai 窗口内继续高频提交。值得记录的公开 commit 包括：迁移 Computer Use 到 cross-platform `cua-driver`、为 ACP 增加 dedicated agent permission dialog、导入 Claude MCP servers、daemon 避免重放截断 session diffs、持久化 goal status 到 daemon transcript events、硬停重复 identical tool calls、统一 retry delay policy、补 response token prompt estimate、缺失 usage metadata 时也能压缩、限制 foreground shell output capture、限制 hard rescue compression retries、避免 dual-output FIFO startup blocking。
