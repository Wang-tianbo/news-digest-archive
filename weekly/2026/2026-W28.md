## 本周主线

本周真正持续出现的主线，是前沿模型发布与 agent 运行时治理首次在同一周强耦合。OpenAI 发布 GPT-5.6，并同步进入 ChatGPT、Microsoft 365 Copilot、GitHub Copilot 与 OpenAI Agents SDK；GitHub 还把 GPT-5.6 拆成 Sol、Terra、Luna 三类 Copilot 端模型变体，说明模型影响力越来越取决于分发层、场景分层和企业策略。

同时，Codex、Claude Code、Qwen Code、Copilot CLI、Dify Agent、LobeHub、Vercel AI SDK、Pydantic AI 和 LangChain 都在补同一类底座：写权限审批、MCP 认证、工具定义漂移检测、系统代理、远程控制、后台任务恢复、workspace runtime、mobile session 接管、prompt cache、tool-call sanitization 和框架边界条件。

中国侧本周有两类信号：一类是腾讯混元 Hy3 开源和 Kimi K2.7 Code 进入 Copilot 企业模型选择器，说明中国模型通过开源权重或主流开发者平台获得全球可见性；另一类是 Qwen Code、Dify Agent、LobeHub、RAGFlow、SGLang 在 agent runtime、低代码 agent、桌面客户端、RAG 工程和 serving 框架上的连续迭代。

研究前沿没有形成单一压倒性论文，但方向高度一致：agent 评测从 SWE-bench 扩向行业流程、真实工具和 proactive agents；长任务 agent 需要主动记忆和状态管理；world model 与具身空间感知开始强调长交互、实时响应和可行动表示；BAIR 则把 agent 之后的核心瓶颈重新表述为数据系统问题。

## 本周评论与判断

基于本周已存档样本的判断，GPT-5.6 是本周最强事实，但不是一个孤立模型事件。真正重要的是它同时进入 OpenAI 自家产品、Microsoft 办公入口、GitHub 开发者入口和 SDK 默认 / request controls，形成“模型发布即进入组织工作流”的样本。未来观察前沿模型时，单看模型页不够，必须同时看 Copilot、Microsoft 365、ChatGPT Work、SDK、CLI、客户端和管理员策略是否同步更新。

基于本周样本的判断，agent 产品竞争已经进入“运行时可治理性”阶段。Codex 的 `writes` approval、MCP interactive auth、system proxy 和 external auth；Claude Code 的 Auto mode 多云、Remote Control、background agent recovery、desktop / mobile / web 进度同步；Qwen Code 的 workspace runtime、subagent loop、memory agent、browser automation gate 和 web shell；这些都在回答同一个问题：长任务 agent 能否被组织托管，而不是只被个人临时使用。

基于本周样本的判断，MCP 和工具调用从“生态连接层”变成“安全与审计层”。Vercel AI SDK 的 tool fingerprint / drift detection、Pydantic AI 的 AG-UI dangling tool-call advisory、CodeQL 的 prompt injection query、Copilot CLI 的 plugin pinning / deny list / sandbox flags，都说明工具定义、消息清洗、prompt sink、插件来源和沙箱策略会成为 agent 平台的核心治理面。

基于本周样本的判断，中国侧需要拆开看。Hy3 和 Kimi K2.7 Code 是模型可见性信号，Qwen Code / Dify / LobeHub / RAGFlow / SGLang 是工程生态信号；它们共同说明中国 AI 生态在开源模型、agent 应用平台、桌面工作台和推理框架上很活跃，但还不能外推为“中国侧整体 agent runtime 已成熟”。当前最扎实的连续样本仍是 Qwen Code 和中文开源应用 / 客户端生态。

基于本周样本的判断，社区观点最有价值的不是“谁更强”的热评，而是产品边界和方法论反馈。宝玉、Simon Willison、Latent Space、AI Snake Oil / NormalTech、Pydantic / Vercel release notes 等样本共同指向：用户和开发者真正需要理解的是云端任务、本地文件、桌面权限、MCP 工具、成本缓存、agent UI 安全和退出成本。
