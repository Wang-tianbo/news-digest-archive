## 今日最重要的 4 条更新

### 1. OpenAI 发布 `Codex 0.136.0` 稳定版，把 archive、remote-control 与安全硬化一起推上公开面

- 发生了什么：`openai/codex` 于 `2026-06-02 01:49` Asia/Shanghai 发布 [rust-v0.136.0](https://github.com/openai/codex/releases/tag/rust-v0.136.0)。主要新增包括：`/archive` 与 `codex archive` / `codex unarchive`、app-server thread resume 初始 turns page、MCP server status、`codex app-server --stdio`、remote execution 的 `CODEX_API_KEY` 注册、remote-control server token、Windows sandbox setup alpha，以及图片生成扩展管线。Bug fix 则覆盖 `/diff` 不再触发仓库内 Git helper / hook、Origin header websocket 拒绝、ChatGPT token 刷新、安全规则与恢复体验。
- 为什么重要：这不是单点小版本，而是把 `session 生命周期管理`、`remote 接入`、`sandbox / diff 安全`、`组织接入面` 放进同一个稳定版。它更像是 Codex 从“能跑任务”转向“能被长期接入”的一次公开推进。
- 来源：
  [Codex Release - rust-v0.136.0](https://github.com/openai/codex/releases/tag/rust-v0.136.0)

### 2. GitHub 在 `2026-06-01` 启用 Copilot 全计划 usage-based billing，并把预算与 code review runner 一起纳入治理面

- 发生了什么：GitHub 于 `2026-06-01` 发布 [Updates to GitHub Copilot billing and plans](https://github.blog/changelog/2026-06-01-updates-to-github-copilot-billing-and-plans/)。官方确认从 `2026-06-01` 起，所有 Copilot 计划都按 `GitHub AI Credits` 计费；用户在用完月度包含额度后，可通过 additional spending budget 继续使用；组织与企业可用 `user-level budgets` 做统一预算控制；Copilot code review 从 `2026-06-01` 起还会消耗 `GitHub Actions minutes`；现有 Student、Pro、Pro+ 用户可升级到 `Copilot Max`。
- 为什么重要：这说明 Copilot 的竞争焦点已经不只是模型或 UI，而是 `agent 工作流的成本控制、组织预算和默认基础设施`。当 code review 同时消耗 AI Credits 和 Actions minutes 时，GitHub 实际上是在把 agent 使用纳入更完整的平台治理账本。
- 来源：
  [GitHub Changelog - Updates to GitHub Copilot billing and plans](https://github.blog/changelog/2026-06-01-updates-to-github-copilot-billing-and-plans/)

### 3. Qwen Code nightly 继续补长会话恢复与 OOM 风险

- 发生了什么：`QwenLM/qwen-code` 于 `2026-06-02 08:46` Asia/Shanghai 发布 [v0.17.0-nightly.20260602.cea15a118](https://github.com/QwenLM/qwen-code/releases/tag/v0.17.0-nightly.20260602.cea15a118)。除了延续前一天 nightly 的 memory pressure monitor、oversized resumed history guard、Anthropic empty stream error surface、settings JSON corrupted warning 等项，这次额外加入 `replace full-history structuredClone with shallow/tail variants to prevent OOM on resume`、`persist /memory toggle state`、`false compressed turn error` 修补等长会话恢复相关改动。
- 为什么重要：相比 `2026-06-01` 已覆盖的上一版 nightly，这一版的新增价值在于它把 `防 OOM resume` 这条线继续坐实了。说明 Qwen Code 不只是发现 memory pressure，而是在继续压实恢复路径的实现细节。
- 来源：
  [Qwen Code Release - v0.17.0-nightly.20260602.cea15a118](https://github.com/QwenLM/qwen-code/releases/tag/v0.17.0-nightly.20260602.cea15a118)

### 4. Google 在 `2026-06-01` 关停 Gemini 2.0 Flash 与 Flash-Lite 系列旧模型

- 发生了什么：Google 在 [Gemini API changelog](https://ai.google.dev/gemini-api/docs/changelog) 的 `June 1, 2026` 条目中确认，`gemini-2.0-flash`、`gemini-2.0-flash-001`、`gemini-2.0-flash-lite`、`gemini-2.0-flash-lite-001` 已于 `2026-06-01` shut down，并建议迁移到 `gemini-3.5-flash` 或 `gemini-3.1-flash-lite`。
- 为什么重要：这不是新模型 headline，而是平台治理信号。Google 正在持续收缩旧模型面，推动开发者尽快迁移到新代际主线。对使用 Gemini 做 agent、tool calling 和成本优化的团队来说，模型生命周期管理已经变成必须跟踪的运维事项。
