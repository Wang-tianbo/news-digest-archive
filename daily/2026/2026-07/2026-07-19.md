### Beyond Success Rate：面向攻防安全 agent 的成本感知评测

- 类型：论文
- 研究问题：安全 agent 评测如果只看成功率，会忽略推理步骤、工具调用、遥测查询和 enrichment 请求带来的真实成本。
- 核心思路：论文在 offensive Cybench 和 defensive Splunk BOTS v1 调查任务上，用固定成本水平比较模型，并拆分 inference spend 与 tool spend。
- 为什么可能影响未来：安全 agent 是 agent 商业化中最容易被 ROI 和风险约束的场景之一。成本感知评测能帮助区分“高预算下能完成”与“真实 SOC 场景中划算且稳定”。
- 局限 / 待验证点：论文仍是 benchmark 视角，是否能覆盖真实企业 SOC 的告警噪声、权限隔离、数据接入和审计流程，还需要生产环境验证。
- 研究成熟度：早期论文 + 公开评测网站。
- 可复现状态：论文公开，评测网站公开；本次未验证代码可复现性。
- 原文链接：[arXiv:2607.15263](https://arxiv.org/abs/2607.15263)
- 权威解读：[Frontier Security evals website](https://evals.frontier.security)
- 我的判断：这条研究信号值得记录，因为它把 agent evaluation 从“能力榜单”拉回“单位成本内的操作价值”，这会直接影响企业安全 agent 的采购与部署。
