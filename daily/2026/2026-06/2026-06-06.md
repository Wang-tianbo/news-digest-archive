## 今日最重要的 5 条更新

### 1. GitHub Copilot：VS Code 支持 enterprise-managed plugins，企业 agent 配置从 CLI 扩到主 IDE

- 发生了什么：GitHub 于 `2026-06-05` 发布 [Enterprise-managed plugins in VS Code in public preview](https://github.blog/changelog/2026-06-05-enterprise-managed-plugins-in-vs-code-in-public-preview)。GitHub 称此前已在 Copilot CLI public preview 中允许企业管理员配置和分发插件；VS Code `1.122` 开始支持同一企业托管能力，企业可以通过 `.github-private/.github/copilot/settings.json` 定义 plugin marketplaces，并自动安装插件。官方强调插件可承载 custom agents、skills、hooks 和 MCP configurations。
- 为什么重要：这是 Copilot 企业治理面向主 IDE 的扩展。它把插件、agent、skills、hooks、MCP 配置和企业账号许可绑定起来，意味着 Copilot 不只是个人开发者工具，而是在进入组织级“默认开发环境配置”层。
- 来源：
  [GitHub Changelog - Enterprise-managed plugins in VS Code in public preview](https://github.blog/changelog/2026-06-05-enterprise-managed-plugins-in-vs-code-in-public-preview)
  [GitHub Docs - Configure enterprise plugin standards](https://docs.github.com/copilot/how-tos/administer-copilot/manage-for-enterprise/manage-agents/configure-enterprise-plugin-standards)

### 2. GitHub Copilot 退役 GPT-5.2 / GPT-5.2-Codex，模型生命周期管理进入企业工作流

- 发生了什么：GitHub 于 `2026-06-05` 发布 [GPT-5.2 and GPT-5.2-Codex deprecated](https://github.blog/changelog/2026-06-05-gpt-5-2-and-gpt-5-2-codex-deprecated)，说明 GPT-5.2 和 GPT-5.2-Codex 从多数 Copilot experience 中退役，包括 Copilot Chat、inline edits、ask / agent modes 和 code completions；GPT-5.2 仍可用于 Copilot code review。官方建议迁移到 GPT-5.5 和 GPT-5.3-Codex，并提醒 Copilot Enterprise 管理员可能需要在 model policies 中启用替代模型。
- 为什么重要：这条信息的价值不在单个模型名称，而在 Copilot 已经把模型退役、替代模型和企业 model policies 绑在一起。随着 agent 工作流进入 CI、IDE、CLI 和 cloud agent，模型生命周期会直接影响企业自动化脚本、默认策略和开发者体验。
- 来源：
  [GitHub Changelog - GPT-5.2 and GPT-5.2-Codex deprecated](https://github.blog/changelog/2026-06-05-gpt-5-2-and-gpt-5-2-codex-deprecated)
  [GitHub Docs - Supported AI models in GitHub Copilot](https://docs.github.com/copilot/reference/ai-models/supported-models)

### 3. Claude Code `v2.1.166` 增加 fallbackModel，并加固跨会话消息和 managed settings

- 发生了什么：`anthropics/claude-code` 于 `2026-06-06 08:55` Asia/Shanghai 发布 [v2.1.166](https://github.com/anthropics/claude-code/releases/tag/v2.1.166)。主要新增包括 `fallbackModel`，可在主模型过载或不可用时按顺序尝试最多三个备选模型，且 `--fallback-model` 也适用于 interactive sessions；deny rule 的 tool-name 位置支持 glob；跨会话 `SendMessage` 转发的消息不再携带用户权限，接收方拒绝 relayed permission requests，auto mode 也会阻断；thinking 可通过 `MAX_THINKING_TOKENS=0`、`--thinking disabled` 或 per-model toggle 关闭。修复项包括远程 session 启动时 worker registration 短暂中断导致永久卡死、managed settings 无效条目导致剩余策略静默失效、MCP server predicate 的 `${VAR}` 匹配、git worktree background agent crash-loop、macOS orphan `claude --bg-pty-host` 100% CPU、Windows PowerShell validation hang、JetBrains 终端闪烁等。
- 为什么重要：这是一组“后台 agent 可被长期运行”的补丁。fallback model 处理供应侧波动，跨会话消息权限隔离处理 agent 间安全边界，managed settings 修复处理组织策略可靠性。Claude Code 的差异化仍在真实长任务的韧性和治理。
- 来源：
  [Claude Code Release - v2.1.166](https://github.com/anthropics/claude-code/releases/tag/v2.1.166)

### 4. Codex `0.138 alpha` 继续推进 remote-control、multi-agent v2 加密、sandbox telemetry 和 plugin runtime

- 发生了什么：`openai/codex` 于 `2026-06-06 07:27` Asia/Shanghai 发布 [rust-v0.138.0-alpha.5](https://github.com/openai/codex/releases/tag/rust-v0.138.0-alpha.5)。该 release note 本身只是版本标记，但 `0.138.0-alpha.4...alpha.5` 的官方 commit 历史显示，本轮包含 remote-control pairing while disabled、pairing status transport / RPC、multi-agent v2 message payload encryption、sandbox outcome telemetry event、turn profiling analytics、remote MCP servers in plugin read、plugin service startup sync 降低 GitHub 下载流量、environment shell info、Windows sandbox / proxy-routed Linux sandbox / TUI 修复等变化。
- 为什么重要：这些都是 agent runtime 的底层系统能力。尤其是 multi-agent v2 消息加密、remote-control pairing status、sandbox outcome telemetry 和 plugin metadata，说明 Codex 正在把“远程控制 + 多 agent + 插件 + 沙箱 + 观测”做成一个更完整的运行时闭环。不过它仍是 alpha 线，稳定版结论应等 `0.138.0` 正式发布后再确认。
- 来源：
