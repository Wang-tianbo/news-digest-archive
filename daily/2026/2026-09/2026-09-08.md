### CUA-Universe：把 hybrid GUI+CLI agent 变成可扩展环境

- 类型：论文
- 研究问题：computer-use agents 主要还在 GUI 路径里打转，真实工作却是 GUI + CLI 混合的。
- 核心思路：论文提出可扩展、动态的 hybrid GUI+CLI 环境，用来支撑更真实的 computer-use trajectory。
- 为什么可能影响未来：它补的是 agent 训练和评测环境，不是模型参数，正好接在今天的 workflow observability 主线上。
- 局限 / 待验证点：摘要层面还不能确认环境覆盖、难度分布和复现质量。
