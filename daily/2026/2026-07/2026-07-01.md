## 今日评论与判断

基于本期已确认事实样本的判断，Sonnet 5 的关键不只是“又一个新模型”，而是把更强 agentic capability 放回相对便宜、默认、广泛可用的 Sonnet 档位。Anthropic 明确强调它在 coding、tool use、reasoning、knowledge work 上较 Sonnet 4.6 提升，并给出 2026-08-31 前 $2 / $10 每百万 token 的 API 促销价；这会直接影响 coding agent 的单位任务成本。

基于本期样本的判断，GitHub 的动作说明 Copilot 正在从单一插件体验变成多 IDE、多 agent、多模型的分发层。JetBrains AI Assistant 里把 Copilot 作为原生 agent picker 选项，同时支持模型选择和 reasoning depth，本质上是在 IDE 内暴露“agent 执行器 + 模型档位 + 成本/深度旋钮”。

基于本期样本的判断，企业采用的瓶颈继续从“有没有模型”转向“谁来控制预算和默认项”。Claude Code 的组织默认模型、Copilot CLI 的 session credit 下限、GitHub cost center 的 per-user AI credit budgets，都是把 agent 使用纳入组织治理的同一组信号。

基于本期样本的判断，DeepSeek DeepSpec 值得放进跟踪清单，但还不应过度解读。它是 speculative decoding 训练和评测代码库，和 DeepSeek / Qwen / MiniMax 等模型在 vLLM、llama.cpp 中被快速支持的趋势相互呼应；真正需要观察的是后续是否出现可复现实验、与 DeepSeek-V4 或开源 serving 框架的明确结合。

### 1. Anthropic 发布 Claude Sonnet 5：面向 agentic coding、工具使用和知识工作的 Sonnet 档升级

- 发生了什么：Anthropic 于 2026-06-30 发布 [Claude Sonnet 5](https://www.anthropic.com/news/claude-sonnet-5)。官方称该模型在 reasoning、tool use、coding、knowledge work 等 agentic performance 上显著强于 Sonnet 4.6，部分高 effort 任务可接近 Opus 4.8；Sonnet 5 面向 Free / Pro 作为默认模型，也面向 Max / Team / Enterprise、Claude Code 和 Claude Platform 开放。API 模型名为 `claude-sonnet-5`，促销价到 2026-08-31 为每百万输入 token 2 美元、输出 token 10 美元，之后为 3 / 15 美元。
- 为什么重要：Sonnet 档位通常是开发者工具和企业工作流的主力成本带。Sonnet 5 如果在 coding / tool use 上接近更贵的 Opus 档，会降低长任务 agent、CLI agent、IDE agent 的运行成本，并改变默认模型选择。
- 来源：[Anthropic - Introducing Claude Sonnet 5](https://www.anthropic.com/news/claude-sonnet-5)、[Claude Code Release `v2.1.197`](https://github.com/anthropics/claude-code/releases/tag/v2.1.197)

- 新出现了什么：Sonnet 5 在同一窗口内完成“发布 - Claude Code 默认 - Copilot CLI / Cline 接入”的快速扩散，说明模型到 agent runtime 的传播速度继续加快。
- 被削弱了什么：本期中国模型公司没有新的基础模型 headline；火山方舟、百度千帆等文档更新时间痕迹暂不足以单独作为重大更新。
