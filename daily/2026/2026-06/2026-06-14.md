### 3. Claude Agent SDK `0.2.101` 修后台任务 lifecycle 事件类型

- 发生了什么：`anthropics/claude-agent-sdk-python` 于 `2026-06-13 09:38` Asia/Shanghai 发布 [v0.2.101](https://github.com/anthropics/claude-agent-sdk-python/releases/tag/v0.2.101)。Release note 写明，SDK 将 terminal `system/task_updated` events 暴露为 typed `TaskUpdatedMessage`，包含 `task_id`、`patch`、`status`、`session_id`、`uuid` 等字段；依赖这些事件追踪 active background tasks 的消费者，不会因为任务结束时只有 `task_updated` 而没有对应 `TaskNotificationMessage` 继续挂起。该版本同时把 bundled Claude CLI 更新到 `2.1.177`。
- 为什么重要：这类更新很小，但正中 agent SDK 的可靠性问题。企业或内部平台要把 Claude Code 当后台 worker 调用时，任务状态事件必须可类型化、可终止、可清理，否则长任务编排会出现“实际完成但上层还在等”的悬挂状态。
- 来源：[Claude Agent SDK Python Release - v0.2.101](https://github.com/anthropics/claude-agent-sdk-python/releases/tag/v0.2.101)

### 4. llama.cpp 连续 release，补 MoE 架构、Vulkan 和 UI / template 小修

- 发生了什么：`ggml-org/llama.cpp` 在本窗口发布 `b9620` 至 `b9627` 多个版本，较有信息量的条目包括 [b9626](https://github.com/ggml-org/llama.cpp/releases/tag/b9626) 增加 `cohere2-MoE` 架构支持、[b9622](https://github.com/ggml-org/llama.cpp/releases/tag/b9622) 支持 Vulkan non-contiguous unary / GLU ops、[b9624](https://github.com/ggml-org/llama.cpp/releases/tag/b9624) 做 UI build-time gzip compression，以及若干 Jinja / UI / server static assets 修复。
- 为什么重要：这不是应用层热点，但 llama.cpp 的模型架构支持、Vulkan kernel 和模板兼容性会持续影响本地推理、桌面 agent 和边缘部署工具链。今天的信号属于基础设施连续维护，而不是单点爆发。
