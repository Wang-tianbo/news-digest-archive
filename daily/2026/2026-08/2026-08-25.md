## 我的判断

> 基于本期已确认事实、可复查观点样本和研究原文，不代表全市场完整样本。

- 基于本期样本的判断：今天不是单个大模型发布日，而是 agent 运行时的“控制面日”。Claude Code 在组织登录、模型选择、成本口径、prompt cache、MCP 恢复和 subagent 可观测性上集中补齐；Codex 在 task TUI、插件 MCP 环境、Guardian 分类、sandbox、subagent ownership 和审批证据上加厚；Qwen Code 则把 WebShell、review convergence、workflow opt-in、Computer Use skill 和第三方模型接入继续推到同一条线上。
- 哪些是趋势：agent 产品正在把长期任务拆成可管理的组织对象：有任务、队列、子代理、workflow、权限、成本、缓存、远程恢复和审查结论。Qwen-MM-Plugins 这种“让多个 harness 复用同一组多模态能力”的项目，也说明竞争不只发生在单一 CLI，而会发生在能力包、skill、MCP 和 harness 之间的可移植层。
- 哪些可能只是噪声：只发布自动化 canary、没有稳定语义的仓库时间戳、以及没有原始 release / 文档支撑的社区转述，今天都不应被解读为重大进展。
- 对后续观察的影响：后面需要盯两条风险线：一是 workflow / subagent 自动启动越来越强后，默认授权边界是否足够清楚；二是 persistent memory 进入 agent 后，内容筛查和 provenance ranking 可能不足以防止错误记忆长期污染。

## AI 研究前沿

### 1. Utility Under Attack: Agent Memory Poisoning and the Limits of Content Screening and Provenance Ranking

- 类型：论文
- 研究问题：当 agent 拥有持久记忆后，错误信息被写入记忆会造成多大长期损害，内容筛查和 provenance ranking 是否足够防御。
- 核心思路：论文用 LongMemEval 语料构造错误断言注入，报告 1.2% 语料被污染时准确率从 0.850 降到 0.300；写入时筛查对 360 条 poisoned memories 的拒绝数为 0；provenance weighting 只有在排除 untrusted content 时才恢复效用，但会压制合法 untrusted evidence。
- 为什么可能影响未来：persistent memory 正成为 agent 产品的默认能力，这篇论文直接提醒“记住更多”会带来持久污染面，且防线不能只靠文本内容判断。
- 局限 / 待验证点：目前是单篇早期论文，结果还需要更多记忆系统、检索器和真实工作流复现。
- 研究成熟度：早期论文
- 可复现状态：论文称 release harnesses、corpora 和 aggregate run reports；本次未验证代码可运行性。
- 原文链接：[arXiv:2608.21230](https://arxiv.org/abs/2608.21230)
- 权威解读：暂无
- 我的判断：这是今天最值得进入长期台账的研究信号；agent runtime 越强调长期记忆，越需要 bounded occupancy、外部 grounding 和记忆写入审计。

### 2. AUSO: Action-Level Unified Skill Optimization from Internalization to Utilization

- 类型：论文
- 研究问题：agent 的 skill 应该如何从外部指导，逐步变成模型策略内部可用、且只在有帮助的动作上发挥作用的能力。
- 核心思路：AUSO 用 action-level unified optimization，把 teacher guidance、environment outcome 和 skill-conditioned / skill-free action 对比结合起来；论文在 ALFWorld、WebShop、SearchQA 上报告优于基线。
- 为什么可能影响未来：今天产品侧大量讨论 skill / MCP / plugin，但研究侧的问题是 skill 如何真正进入策略学习，而不只是被动调用。
- 局限 / 待验证点：仍是 benchmark 论文，是否能迁移到真实 coding agent、长任务和多人协作环境尚待验证。
- 研究成熟度：早期论文
- 可复现状态：未验证
- 原文链接：[arXiv:2608.21292](https://arxiv.org/abs/2608.21292)
- 权威解读：暂无
- 我的判断：它和 Qwen-MM-Plugins、Claude Code skills、Codex plugin runtime 形成有趣呼应：短期是外部能力包，长期是 skill 生命周期和策略内化问题。
