## 主线判断

本期最值得记住的主线是：OpenAI GPT-5.6 预览把“模型能力升级”和“部署治理”放在同一个发布面里。GPT-5.6 Sol 被定位为 OpenAI 当前最强模型，重点覆盖 coding、biology、cybersecurity 和长程 agentic tasks；同时，OpenAI Help Center 明确预览期包括 Sol、Terra、Luna，经 API 和 Codex 向受限组织开放，ChatGPT 不在本次预览范围内。

和过去几天的 agent runtime 修补相比，本期的变化更上层：模型本身开始显式支持更高 reasoning effort 和 subagent orchestration，但访问、监控、额外安全检查、价格与缓存策略也同时进入产品文档。这意味着 frontier model competition 正在从“谁分数更高”进入“谁能把强模型安全、可审计、可计费地交给开发者和企业”的阶段。

中国侧本期没有新的基础模型级官方发布。Qwen Code 继续以 nightly 形式推进 daemon control、Web Shell、skills、OpenAI-compatible pipeline、voice dictation、telemetry 和 provider protocol 映射；llama.cpp 则在严格窗口内连续补 OpenCL flash attention、CUDA strided copy fast path 与 Vulkan / SYCL 小修，构成本地推理 runtime 的工程信号。

## 今日评论与判断

基于本期已确认事实样本的判断，`2026-06-28` 的关键词是“强模型的受控交付”。GPT-5.6 Sol 的能力叙事集中在 coding、science、cybersecurity 和 long-horizon work，但真正影响市场节奏的是它没有直接进入 ChatGPT，而是先通过 API 与 Codex 给受限组织预览。这会让企业开发者、政府安全审查、模型安全评估和 coding agent 产品节奏更强耦合。

基于本期样本的判断，OpenAI 正在把 Codex 放在前沿模型首发链路里。Help Center 明确 GPT-5.6 预览包括 API 与 Codex，且额外安全检查可能跨 API、Codex、未来 ChatGPT 的同一账户活动产生影响。这说明 coding agent 不再只是模型发布后的应用场景，而是前沿模型部署、监控和安全策略的一部分。

基于本期样本的判断，`ultra` 模式值得重点跟踪。OpenAI 在 GPT-5.6 Sol 发布页中把它描述为超出单 agent、使用 subagents 加速复杂工作的模式；这和过去一周 Codex、Claude Code、Copilot CLI、Qwen Code 都在补 background jobs、subagent concurrency、daemon 和 multi-agent UI 的趋势一致。真正的中期变量不是“能不能开多个 agent”，而是复杂任务拆分、权限继承、成本上限和结果校验能否被组织接受。

基于本期样本的判断，本地 / 开源推理框架仍是低传播但高价值的底层变量。llama.cpp 在 OpenCL flash attention、CUDA pitched copy、Vulkan 和 SYCL 上的连续修补，不会单独改变模型格局，但会影响本地 coding agent、边缘设备和私有化部署能否稳定承接更长上下文、更复杂工具链和更低成本推理。

本期 `signal_strength` 评为 `high`：严格窗口内有 OpenAI 前沿模型预览这一强信号，同时 Qwen Code 和 llama.cpp 延续 agent runtime / inference runtime 工程化；补充范围内的 OpenAI Codex 与 compute 基建信号也与主线直接相连。
