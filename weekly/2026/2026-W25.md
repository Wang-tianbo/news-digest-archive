## 本周主线

- 本周最值得记住的主线是：`AI 编程代理正在从交互式助手变成可触发、可迁移、可审查、可计费、可长期运行的自动化系统`。
- GitHub 是本周最强的平台化样本。Copilot app GA、Agent finder / ARD、Auto mode、`AGENTS.md`、Copilot-authored PR 归因、Issue fields MCP、用户级 AI credits 和模型生命周期管理，组合出一个越来越完整的 SDLC agent 控制面。
- OpenAI 的强信号来自 Codex `0.140.0` 与 `0.141.0` 稳定版，以及 `0.142` alpha 的远程执行和 code-mode runtime 重构。Codex 的竞争点继续落在用量、迁移、删除、远程执行、插件 MCP、上下文 lineage、rate-limit credits 和安全传输。
- Qwen Code 是中国侧最连续的公开 coding agent runtime 样本。本周从 `0.18.1` 到 `0.18.5` 连续把 daemon、ACP、workflow isolation、MCP approval、Computer Use、Web Shell、`/loop`、权限、路径、端口、OAuth、MCP resources 和边界校验推进到稳定 release。
- Anthropic 本周没有新的基础模型主线，但 Claude Code 和 Claude Agent SDK 继续强化参数级权限、nested `.claude` 规则、auto mode 危险命令阻断、webhook / scheduled task approval 边界和长任务等待体验。
- Cursor Automations 是本周新增的强产品线索。它把 always-on agents、自然语言配置、Slack / GitHub triggers、computer use、cloud-local handoff、SDK stores 和 nested subagents 放到一起，说明 IDE agent 正在吸收 CI、RPA、Zapier 式自动化和团队工作流的一部分边界。
- llama.cpp、vLLM 与 Gemini API / CLI 的信号说明底层 runtime 也在同步变厚：推理 serving、结构化输出、schema / grammar、tool parser、语音流式输出、本地 agent server 和私有化 backend 都在补生产化细节。

## 本周评论与判断

- 基于本周样本的判断，`agent runtime governance` 已经不是一个抽象趋势，而是每天都在 release note 里落地的工程对象。危险命令阻断、tool input pre-approval、workspace boundary、MCP auth / resources、路径与端口校验、session deletion、usage credits、remote shell / cwd 和 trigger approval 都是企业能否放大 agent 使用的前置条件。
- 基于本周样本的判断，GitHub 的优势正在从 Copilot 模型能力转向平台控制面。它把桌面入口、资源发现、模型路由、code review、issue、PR、release notes、billing metrics 和 MCP support 接回 GitHub 原生对象，这会让 Copilot 更像 SDLC 的默认 agent layer。
- 基于本周样本的判断，OpenAI 与 Qwen 正在用不同节奏回答同一问题：coding agent 如何从 CLI 会话变成长任务执行系统。Codex 更强调远程执行、安全传输、插件 / MCP、外部 agent 迁移和上下文 lineage；Qwen Code 更强调高密度运行时硬化、daemon / ACP、Web Shell、workflow isolation 和边界校验。
- 基于本周样本的判断，Anthropic 对 Claude Code 的更新开始明显偏“默认安全基线”。auto mode 对 destructive git / IaC 操作的约束、scheduled task / webhook 不能批准 pending action、参数级权限和 nested subagent 治理，都是无人值守 agent 必须先解决的问题。
- 基于本周样本的判断，基础模型 headline 本周继续转弱。值得记录的模型相关变化更多发生在平台路由、生命周期、推理优先级、API deprecation、speech streaming 和本地 serving，而不是新一代基础模型发布。
