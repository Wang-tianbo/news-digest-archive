## 今日最重要的 4 条更新

### 1. Google 在 2026-05-19 推出 Managed Agents in the Gemini API，并同步扩展 Antigravity 2.0、Antigravity CLI 与 AI Studio

- 发生了什么：Google 于 2026-05-19 发布 [Introducing Managed Agents in the Gemini API](https://blog.google/innovation-and-ai/technology/developers-tools/managed-agents-gemini-api/) 和 [Building the agentic future: Developer highlights from I/O 2026](https://blog.google/innovation-and-ai/technology/developers-tools/google-io-2026-developer-highlights/)。官方确认开发者可以通过单次 API 调用启动能推理、调工具、执行代码的 agent，并运行在隔离的 Linux 环境中；同时推出 `Antigravity 2.0` 桌面应用、`Antigravity CLI`、`Antigravity SDK`、AI Studio 移动端预注册和导出到 Antigravity 的工作流。
- 为什么重要：Google 这次不是只发模型，而是在 `agent runtime + managed infrastructure + developer surfaces` 三层同时推进。特别是 `Persistent, isolated environments` 和 `Interactions API`，说明它开始把托管 agent 当成正式平台能力，而不是只保留在自家产品里。
- 来源：  
  [Google - Introducing Managed Agents in the Gemini API](https://blog.google/innovation-and-ai/technology/developers-tools/managed-agents-gemini-api/)  
  [Google - Building the agentic future: Developer highlights from I/O 2026](https://blog.google/innovation-and-ai/technology/developers-tools/google-io-2026-developer-highlights/)  
  [Gemini API Interactions 文档](https://ai.google.dev/gemini-api/docs/interactions)

### 2. GitHub 在 2026-05-19 将 Gemini 3.5 Flash 作为 GitHub Copilot 的正式可用模型上线

- 发生了什么：GitHub 于 2026-05-19 发布 [Gemini 3.5 Flash is generally available for GitHub Copilot](https://github.blog/changelog/2026-05-19-gemini-3-5-flash-is-generally-available-for-github-copilot/)。
- 为什么重要：GitHub 官方把 Google 的 Flash 级模型纳入 Copilot 正式模型池，意味着 Copilot 的模型层不再只是“是否支持某模型”，而是开始围绕 `速度 / 成本 / 质量` 做更细粒度的工作流选择。对 AI coding agent 来说，快模型的正式可用直接影响批量修复、代码审查、辅助实现等低延迟场景。
- 来源：  
  [GitHub Changelog - Gemini 3.5 Flash is generally available for GitHub Copilot](https://github.blog/changelog/2026-05-19-gemini-3-5-flash-is-generally-available-for-github-copilot/)  
  [GitHub Copilot 文档首页](https://docs.github.com/en/copilot)

### 3. GitHub 在 2026-05-19 把 Copilot cloud agent 更深地嵌入代码评审修复工作流

- 发生了什么：GitHub 于 2026-05-19 发布 [Easily apply Copilot code review feedback with Copilot cloud agent](https://github.blog/changelog/2026-05-19-easily-apply-copilot-code-review-feedback-with-copilot-cloud-agent/)。`Implement suggestion` 被改成 `Fix with Copilot`，并新增对话框来选择直接改当前 PR、另开 PR、指定模型、补充附加指令；同时新增 `Fix batch with Copilot` 批量处理多个 review comment。
- 为什么重要：这说明 Copilot cloud agent 正在从“收到指令后执行”走向“直接接管代码审查后的修复交付节点”。当多条 review comment 可以批量交由 cloud agent 处理时，Copilot 的角色更接近 PR 协作者，而不是旁路助手。
- 来源：  
  [GitHub Changelog - Easily apply Copilot code review feedback with Copilot cloud agent](https://github.blog/changelog/2026-05-19-easily-apply-copilot-code-review-feedback-with-copilot-cloud-agent/)  
  [GitHub Copilot 功能页](https://github.com/features/copilot)
