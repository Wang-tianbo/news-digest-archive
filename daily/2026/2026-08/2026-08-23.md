### Inducing Task Models from Computer-Use Traces

- 类型：论文
- 研究问题：能否从自然记录的电脑使用轨迹中诱导出可审计、可复用的任务模型。
- 核心思路：把截图、鼠标和键盘轨迹转成符号化任务表示。
- 为什么可能影响未来：agent 进入真实工作流后，这类轨迹到任务模型的数据层会越来越关键。
- 局限 / 待验证点：隐私、覆盖度和跨组织泛化都还要验证。
- 研究成熟度：早期论文
- 可复现状态：未验证
- 原文链接：[arXiv:2608.20319](https://arxiv.org/abs/2608.20319)
- 权威解读：暂无
- 我的判断：这是今天最像 agent 时代数据基础设施的研究信号之一。

### Learning When to Think: Adaptive Reasoning for Test-Time Compute Allocation

- 类型：论文
- 研究问题：如何让推理模型在不同难度任务上自适应分配 test-time compute。
- 核心思路：把“思考多少”从固定预算改成动态分配问题。
- 为什么可能影响未来：如果成立，compute routing 会成为推理系统的重要控制面。
- 局限 / 待验证点：是否能稳定迁移到真实任务和更大模型还要看。
- 研究成熟度：早期论文
- 可复现状态：未验证
- 原文链接：[arXiv:2608.20256](https://arxiv.org/abs/2608.20256)
- 权威解读：暂无
- 我的判断：这类工作把“会不会想”进一步拆成“何时想、想多久”。

### MidTool: Mid-training Data Synthesis for Agentic Tool Use

- 类型：论文

- 为什么可能影响未来：如果这条路成立，很多 agent 能力会更依赖数据和训练阶段设计。
