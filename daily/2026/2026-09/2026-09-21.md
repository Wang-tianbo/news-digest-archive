## AI 研究前沿

### 1. Coding Agents with an Obstacle-Aware Harness for Safe Robot Manipulation

- 类型：论文
- 研究问题：语言模型写机器人控制程序的 coding-agent 范式，如何在没有机器人专门训练的情况下保证物理环境安全。
- 核心思路：论文提出 obstacle-aware harness，让 coding agent 在生成/执行机器人控制代码时显式考虑障碍物与安全约束。
- 为什么可能影响未来：这把 software coding agent 的 harness 思路迁移到机器人 manipulation，说明“agent 安全边界”正在从文件/终端扩展到物理动作。
- 局限 / 待验证点：早期论文；需要看不同机器人、不同场景和真实硬件上的复现效果。
- 研究成熟度：早期论文
- 可复现状态：论文公开，未确认第三方复现
- 原文链接：[arXiv:2609.20822](https://arxiv.org/abs/2609.20822v1)
- 权威解读：暂无
- 我的判断：这篇值得放进长期台账，因为它把 coding agent 的“写程序”能力直接接到物理世界风险。

### 2. Workspace Models：用 saliency supervision 做轻量机器人长期记忆

- 类型：论文
- 研究问题：复杂机器人 manipulation 需要长期记忆，但全历史条件化容易引入伪相关并降低性能，如何压缩出任务相关记忆。
- 核心思路：Workspace Models 使用 saliency-driven supervision 学习轻量 memory 表示，用于保留过去事件和动作中对当前任务关键的部分。
- 为什么可能影响未来：长任务 agent 的共同瓶颈是状态管理；机器人 workspace memory 给软件 agent 的长期上下文压缩也提供了相似问题结构。
- 局限 / 待验证点：仍需跨任务、跨环境和真实部署验证；saliency supervision 的标注/泛化成本需要观察。
- 研究成熟度：早期论文
- 可复现状态：论文公开，未确认第三方复现
- 原文链接：[arXiv:2609.20820](https://arxiv.org/abs/2609.20820v1)
- 权威解读：暂无
- 我的判断：它和 coding-agent context compaction 是同一类问题：不是记住全部，而是证明哪些状态值得保留。

### 3. Google Research MilleMiglia：面向中程物流的现实实例生成器

- 类型：研究博客 / benchmark
- 研究问题：如何为 middle-mile logistics 生成更接近真实复杂度的优化实例，用于测试算法和系统能力。
- 核心思路：Google Research 发布 MilleMiglia，作为现实感更强的物流实例生成器。
- 为什么可能影响未来：AI agent 进入企业运营和供应链时，需要的不只是语言能力，还需要可复现、可压测的任务环境。
- 局限 / 待验证点：研究博客级信号；需要看开源程度、行业采用和与真实物流数据的偏差。
- 研究成熟度：研究博客 / 任务生成器
- 可复现状态：博客公开，复现状态待查
- 原文链接：[Google Research - MilleMiglia](https://research.google/blog/millemiglia-a-realistic-instance-generator-for-middle-mile-logistics/)
- 权威解读：作者博客
- 我的判断：这类 task generator 会变成企业 agent 评估基础设施的一部分。
