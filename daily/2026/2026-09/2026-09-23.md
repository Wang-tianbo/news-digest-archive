## AI 研究前沿

### 1. Harness-Zero：用 Agent-as-Harness 蒸馏可迁移的 agent harness

- 类型：论文
- 研究问题：agent harness 能显著提升模型和环境交互表现，但最佳 harness 往往绑定特定领域、实例和模型，如何把 harness 的增益迁移到更通用的部署场景。
- 核心思路：论文提出 Harness-Zero / harness distillation，把 agent-as-harness 的交互经验转化为可复用的 harness 能力，试图降低部署时对特定外部系统的依赖。
- 为什么可能影响未来：如果 harness 可以被蒸馏或迁移，agent 产品的竞争会从“谁有更复杂的外部脚手架”转向“谁能把脚手架经验变成可复用能力”。
- 局限 / 待验证点：早期论文，仍需看任务覆盖、跨模型泛化和真实软件环境复现；不能直接等同于生产 agent 能力提升。
- 研究成熟度：早期论文
- 可复现状态：论文公开，未确认第三方复现
- 原文链接：[arXiv:2609.24974](https://arxiv.org/abs/2609.24974v1)
- 权威解读：暂无
- 我的判断：它和本期 Codex / Claude Code / Qwen Code 的 runtime 治理互相呼应：agent 的能力越来越多来自模型之外的 harness 结构。

### 2. DolphinBench：给 agent memory 画 Pareto frontier

- 类型：benchmark / 论文
- 研究问题：真实 agent 需要长期记忆和上下文召回，但现有 memory benchmark 多是问答格式，不能很好刻画行动中记忆的成本、收益和失败模式。
- 核心思路：DolphinBench 试图评估 agent memory 的效果与代价，让不同记忆机制在更接近行动依赖的任务中比较 Pareto frontier。
- 为什么可能影响未来：如果 memory 评估从“答对历史问题”转向“行动是否因记忆变好”，会直接影响 coding agent、浏览器 agent 和个人 assistant 的长期状态设计。
- 局限 / 待验证点：benchmark 本身还需社区采用；评价任务是否代表真实生产工作流仍待观察。
- 研究成熟度：早期 benchmark / 论文
- 可复现状态：论文公开，代码复现状态待查
- 原文链接：[arXiv:2609.24971](https://arxiv.org/abs/2609.24971v1)
- 权威解读：暂无
- 我的判断：本期产品侧都在补 session、transcript、background task 和 worktree；DolphinBench 提供了一个研究侧问题：这些记忆到底该如何证明有用。

### 3. Rare Event Estimation via Iterative Unalignment：估计 autonomous agent 的低概率灾难事件

- 类型：论文
- 研究问题：自主 agent 的灾难性事件可能极罕见，但部署风险取决于这些事件发生频率，而不是平均表现。
- 核心思路：论文提出用 iterative unalignment 估计 rare event 概率，尝试在不只依赖自然采样的情况下发现低概率高影响轨迹。
- 为什么可能影响未来：当 agent 开始执行文件、浏览器、代码、云环境和企业流程，rare event 估计会比普通 benchmark accuracy 更接近治理需求。
- 局限 / 待验证点：方法仍需在真实部署、不同模型和不同安全策略下验证；“unalignment”构造本身可能引入分布偏差。
- 研究成熟度：早期论文
- 可复现状态：论文公开，未确认第三方复现
- 原文链接：[arXiv:2609.24969](https://arxiv.org/abs/2609.24969v1)
- 权威解读：暂无
- 我的判断：这条研究信号值得和 Claude Code symlink / auto mode retry、Codex sandbox gaps、Gemini CLI ACP permission ordering放在一起看：agent 安全的难点正在从常见错误扩展到罕见轨迹。
