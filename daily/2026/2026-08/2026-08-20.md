- 哪些是趋势：一是「agent 托管 / 订阅化」与「统一 harness 评测」同时出现，意味着社区开始要求 agent 具备可重复、可审计的运行契约；二是中国模型公司进入「开源节奏 + 规模」双线竞争，GLM-5.3 与 Kimi K3 同分并承诺 08-28 开源权重，字节 Seed 为超 5 万亿参数模型调整组织架构，暗示下一轮竞争是超大规模基模与开源生态同步推进；三是多模态正侵入 agent 执行层（DeepSeek Harness 支持图像输入）。

## AI 研究前沿

### 1. StagedWorkspace: A Versioned Workspace for Knowledge-Work Agents

- 类型：论文
- 研究问题：知识型 agent 所搜索的解析视图、所编辑的原始文件、所审查的变更、所提交的产物可能指向同一工作产物的不同版本，如何建立一致的工作区状态契约。
- 核心思路：提出 StagedWorkspace，把解析记录与审查 diff 绑定到原生文件变化时的内容哈希；在 OfficeQA Pro 与 APEX-Agents 的固定 harness 消融中，dual parsed/native 访问对所有测试模型都取得最高点估计，相对单一视图提升 OfficeQA Pass@1 8.3-12.1 分。
- 为什么可能影响未来：把「agent 工作区版本契约」形式化，直接支撑 agent 在文档/表格/幻灯片等混合格式项目中的可审计执行，是 agent 基础设施的关键缺口。
- 局限 / 待验证点：仍属固定 harness 消融，真实多 agent、多格式、长任务下的泛化与工程成本待验证。
- 研究成熟度：早期论文
- 可复现状态：作者开源待确认（原文未在摘要给出代码链接）
- 原文链接：[arXiv:2608.18050](https://arxiv.org/abs/2608.18050)
- 权威解读：暂无
- 我的判断：与本期「agent 执行基础设施」主线高度契合；若代码开源，值得纳入 harness 对比基准。

### 2. On the Fragility of Self-Improving Agents: Variance, Task Order, and Underspecification

- 类型：论文
- 研究问题：基于记忆的自改进 agent 的可靠性是否被现有评测高估，任务顺序与评估方差会如何影响结论。
- 核心思路：对两种 memory-based 方法做多轮运行量化方差、随机打乱任务顺序重新评估，发现 agent 评测在复杂环境与多步任务上固有噪声较大，自改进循环会进一步放大噪声；改进高度依赖任务顺序，默认顺序隐含课程先验；并假设任务与环境 underspecification 是脆弱性来源并加以验证。
- 为什么可能影响未来：为「自改进 agent」提供更严格的可靠性基线，避免把噪声当作能力提升，直接影响 agent 评测与研发标准。
- 局限 / 待验证点：结论主要针对两类 memory-based 方法，覆盖范围与更大规模环境的普适性待进一步验证。
- 研究成熟度：早期论文
- 可复现状态：作者开源（代码 + 数据集）
- 原文链接：[arXiv:2608.18066](https://arxiv.org/abs/2608.18066)
- 权威解读：暂无
- 我的判断：与 HarnessEval、DeepSeek Harness 共同构成「agent 评测需要更严格、更可复现」的研究侧证据；Salesforce 代码开源使其可复现性更强。
