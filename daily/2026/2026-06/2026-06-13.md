## 今日最重要的 5 条更新

### 1. Anthropic 称美国政府 directive 要求暂停 Fable 5 / Mythos 5 访问

- 发生了什么：Anthropic 于 `2026-06-12` 发布 [Statement on the US government directive to suspend access to Fable 5 and Mythos 5](https://www.anthropic.com/news/fable-mythos-access)。官方称美国政府以国家安全权限发出 export control directive，要求暂停任何 foreign national 对 Fable 5 和 Mythos 5 的访问，包括美国境内外的 foreign national Anthropic employees；Anthropic 表示为确保合规，必须对所有客户临时关闭 Fable 5 / Mythos 5，其他 Anthropic 模型不受影响。Anthropic 还称政府理由与一个潜在 narrow jailbreak 有关，并表示正在配合但不同意该标准。
- 为什么重要：这是前沿模型发布后迅速遇到政策 / 安全访问中断的强信号。它说明模型能力、安全争议和国家安全权限会直接影响客户可用性，也会推动企业更重视 fallback、供应商冗余和模型访问风险管理。
- 来源：[Anthropic - Fable / Mythos access statement](https://www.anthropic.com/news/fable-mythos-access)

### 2. OpenAI 将收购 Ona，补 Codex 持久云执行环境

- 发生了什么：OpenAI 于 `2026-06-11` 发布 [OpenAI to acquire Ona](https://openai.com/index/openai-to-acquire-ona/)。官方称 Ona 的 secure cloud execution and orchestration technology 将进入 Codex 生态，帮助 Codex 在客户控制的云环境中执行长时间 agent 工作。OpenAI 称 Codex 每周用户已超过 `5 million`，较年初增长 `400%`；Ona 曾帮助 `2 million` 开发者使用 secure, reproducible cloud environments。
- 为什么重要：这是 Codex 从本地 / 会话式 agent 走向企业持久执行基础设施的重要补位。OpenAI 明确强调 credentials scope、activity logs、review flow、客户自有云边界和生产 workflow，这与 GitHub / Claude / Qwen 同期围绕 runner、allowlist、trace 和 workflow 的方向一致。
- 来源：[OpenAI - OpenAI to acquire Ona](https://openai.com/index/openai-to-acquire-ona/)

### 3. GitHub Copilot code review 增加组织 runner、内容排除和无字符限制 custom instructions

- 发生了什么：GitHub 于 `2026-06-12 21:37 UTC` 发布 [Copilot code review: New configurations and controls](https://github.blog/changelog/2026-06-12-copilot-code-review-new-configurations-and-controls/)。更新包括组织级 runner type configuration，可把默认 runner 应用于组织内所有仓库并锁定覆盖仓库配置；Copilot code review 现在遵守 repository / organization / enterprise 的 Copilot content exclusion settings；`.github` 下 `copilot-instructions.md` 与 `*.instructions.md` 过去 `4000` 字符读取限制被移除。
- 为什么重要：Copilot code review 正从“自动审 PR”变成组织可配置的审查基础设施。Runner 决定执行环境，content exclusion 决定哪些代码可被 agent 使用，custom instructions 则让团队把长期工程规则灌入 review agent。
- 来源：[GitHub Changelog - Copilot code review: New configurations and controls](https://github.blog/changelog/2026-06-12-copilot-code-review-new-configurations-and-controls/)

### 4. Qwen Code `0.18.0` 稳定版发布，把 preview runtime 能力收束成正式版本
