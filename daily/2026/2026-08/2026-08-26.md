## AI 研究前沿

### 1. SWE Refactor Bench：整仓迁移暴露 coding agent 的“通过测试但没完成迁移”问题

- 类型：benchmark / 论文
- 研究问题：当前 coding agent 是否能完成长周期、整仓级技术栈迁移，而不只是让现有测试通过。
- 核心思路：论文提出 SWE Refactor Bench，包含 20 个 whole-repository migrations，覆盖 4 类技术债；评估分为 Migration Audit、Behavioral Tests 和由 6 个独立 coding agents 生成 targeted tests 的 Agentic Verification。论文报告 520 次运行中只有 28 次通过全部三阶段，13/20 个任务没有 accepted solution。
- 为什么可能影响未来：它把 coding agent 评测从 bug fixing 推到 repo migration，并明确区分“真的迁移了”和“行为仍正确”两种能力。
- 局限 / 待验证点：仍是早期论文和基准，任务集合、agent 配置和模型版本需要第三方复现；模型排名也会随新版本快速变化。
- 研究成熟度：早期 benchmark 论文
- 可复现状态：论文原文可查；本次未验证代码可运行性。
- 原文链接：[arXiv:2608.23564](https://arxiv.org/abs/2608.23564)
- 权威解读：暂无
- 我的判断：这是今天最值得进入 coding-agent 长期台账的研究信号。产品侧越强调长任务和自动修复，评测侧越需要这种能抓住“跳过迁移也能过测试”的审计层。

### 2. Prime Agent：把 persistent REPL、memory、skills、subagents 和 resource accounting 做成自改进 harness

- 类型：论文 / 开源实现线索
- 研究问题：长周期 agent 是否需要一个能保留历史、记忆、skills、prompts、subagent specs，并支持递归子代理和资源核算的 harness，而不只是更大的上下文窗口。
- 核心思路：Prime Agent 描述一个 open-source harness：persistent IPython REPL 负责程序化上下文处理和 test-time compute，Continual Harness 保存 histories / memories / skills / prompts / subagents，recursive subagents 通过 agent-to-agent communication 协作，并提供 Agents View、execution / recovery / verification / resource accounting。
- 为什么可能影响未来：如果 coding agent 的能力上限越来越受 harness 限制，那么上下文、工具、记忆、子代理和资源核算的接口会成为新的能力放大器。
- 局限 / 待验证点：论文中的 ARC-AGI-3 RHAE、long-context coding、GPU kernel、emulator、Factorio 等结果需要独立复现；harness 提升和模型本身能力提升也需要拆分评估。
- 研究成熟度：早期技术报告
- 可复现状态：论文称代码可用；本次未验证仓库和实验复现。
- 原文链接：[arXiv:2608.23552](https://arxiv.org/abs/2608.23552)
- 权威解读：暂无
- 我的判断：它和今天产品侧的 MCP / Skill / subagent / background session 更新形成正反馈：短期看是工具壳，长期看是“能力是否能被稳定积累和复用”的系统问题。

### 3. Google Research AgentHands：XR agent 从 2D overlay 走向空间化手势协助

- 类型：研究博客
- 研究问题：当多模态 agent 进入 XR / 物理空间，如何把语言指令变成空间可理解的动作、警示和对象指向，而不是只在屏幕上画 2D bounding box。
- 核心思路：Google Research 在 2026-08-25 发布 AgentHands，描述一个 LLM-powered XR prototype：用场景理解和对象注册把手势锚定到物理环境，生成同步的 GestureEvents，并通过 TTS word-level timestamps 与语音对齐；小规模 within-subjects study 报告相比 speech-only baseline 在 spatial grounding、action understanding 和 warnings 上有提升。
- 为什么可能影响未来：这提示 agent UX 可能从 chat / IDE / browser 扩到 embodied interface，尤其是维修、装配、培训、医疗和现场操作这种需要空间指代的场景。
- 局限 / 待验证点：样本量小，仍是 XR 研究原型；离通用消费级产品和真实生产任务还有距离。
- 研究成熟度：研究博客 / 原型
- 可复现状态：仅有报告与论文入口；本次未验证代码或数据。
- 原文链接：[Google Research - AgentHands](https://research.google/blog/agenthands-generating-interactive-hand-gestures-for-spatially-grounded-agent-conversations-in-xr)
- 权威解读：暂无
- 我的判断：它不是今天的 coding-agent 主线，但值得记录为“agent 交互界面从屏幕走向空间”的早期信号。
