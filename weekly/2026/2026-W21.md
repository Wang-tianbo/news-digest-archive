## 本周主线

- 本周最值得记住的，不是某个新的基础模型 headline，而是 `AI 编程代理开始全面转向平台化运行时竞争`。
- GitHub 这一周把 Copilot 同时往 `远程接管`、`模型自动路由`、`code review 到修复闭环`、`语义 issue 检索` 和 `开源可审计表层` 推进，说明它不再满足于做 IDE 内的辅助层，而是在抢默认工作台。
- OpenAI 的 Codex 则用连续稳定版和 alpha 节奏，把 `remote control`、`goal persistence`、`permission profile`、`remote executor`、`resume`、`memory summary` 与 `plugin runtime` 压成系统层能力，公开面虽然不高调，但工程推进极快。
- Google 是本周最像“平台级出招”的一方。`Managed Agents in the Gemini API`、`Antigravity 2.0`、`Antigravity CLI`、AI Studio 新入口和 Gemini CLI 的 session / subagent 协议更新，共同指向 `托管 agent 基础设施` 正在正式产品化。
- Anthropic 的信号没有 Google 那么 headline 化，但方向同样清晰：Claude Code 连续围绕 `background sessions`、`/code-review`、`/usage` 成本拆解、企业托管 MCP、权限边界和沙箱修补做更新，说明它在把终端代理往组织可治理工具收紧。
- 中国侧本周最有连续公开增量的不是基础模型，而是 `Qwen Code`。从 `0.16.0` 到 `0.16.1` 再到连续 nightly，重点都落在 `worktree`、`goal`、`auto approval`、`tool protocol correctness`、`TTFT telemetry`、`memory-leak-debug` 和构建稳定性上。
- 综合看，本周的反复信号只有一个：`AI agent 的竞争已经从“会不会写”进入“能不能长期跑、怎么被接入、如何被治理、出了问题如何诊断”的新阶段。`

## 本周评论与判断

- 基于本周样本，最重要的趋势是：`agent 产品的主战场已经从功能展示转向运行时与控制面。` 远程控制、goal 持久化、session invocation、subagent protocol、auto model routing、batch code review fix、managed MCP、成本拆解和诊断技能，这些原本像配套能力的东西，本周已经变成主叙事。
- 本周最明显在加速的是 GitHub、OpenAI、Google。GitHub 的动作最完整，覆盖模型层、执行层、协作层和开源信任层；OpenAI 的动作最像持续交付型运行时团队；Google 的动作最像试图一次性搭起托管 agent 平台。
- Anthropic 本周不是放缓，而是把资源明显投入到 `长任务稳定性 + 团队治理细节`。如果后续它把这些底层修补继续串成更完整的企业叙事，Claude Code 的竞争力会更接近长期生产环境，而不只是强模型外壳。
- 中国侧本周被强化的结论是：`公开工程节奏最连续、最可验证的 agent 工具线仍主要是 Qwen Code。` 但同样要承认，它当前仍更强于工程推进，弱于平台化叙事和组织级分发表达。
- 本周另一个明确判断是：`release cadence 本身已经是竞争力。` 当多数高价值信号首先出现在 changelog、release notes 和 docs，而不是发布会或长博客时，观察方法也必须从盯 headline 改成盯连续交付密度。

## 本周判断复盘

### 上周判断哪些被验证

- `竞争焦点正从功能展示转向运行时和治理` 被本周进一步坐实。GitHub 的 task routing 与 review fix、OpenAI 的 permission profile 与 remote-control、Anthropic 的 `/usage` 与企业托管 MCP、Qwen 的 `/doctor` 与 telemetry 都属于同一方向。
- `公开 headline 变少不等于竞争降温` 也被验证。本周后半段美国侧表层 headline 减少，但 Codex、Claude Code、Gemini CLI、Qwen Code 仍持续发版，且增量集中在更接近生产环境的问题。
- `中国侧更值得盯公开 agent runtime，而不是等单一模型 headline` 被强化。真正连续、可验证的中国公开增量基本都来自 Qwen Code 的 release 流。

### 上周判断哪些被修正

- 上周更强调 `团队流程`，本周需要修正为 `团队流程只是外层，真正开始竞争的是托管基础设施、协议、权限、恢复和诊断面`。Google Managed Agents 与 Gemini CLI protocol、OpenAI goal / permission、Qwen diagnostics 把这个判断推进了一层。
- 上周对 GitHub 的判断更偏 `组织管理权`，本周需要补充 `默认调度权`。Auto model selection、Web 端模型收敛和 cloud agent 承接 review 修复，说明 GitHub 不只是想管理使用情况，还在回收模型选择权。

### 本周新增判断

- `托管式 agent 基础设施` 已经从概念进入明确产品阶段，Google 是这一周最强样本。
- `诊断与可观测性` 正在成为公开 agent 工具的新竞争面，Qwen 的 `TTFT capture` 与 `memory-leak-debug`、Anthropic 的 `/usage` 分类和 OpenAI 的 `codex doctor` 都是同类信号。
- `公开可审计表层` 也开始出现。GitHub 开源 Copilot for Eclipse，不会立刻改变份额，但它把 agentic 实现暴露到代码层，说明“能否被组织审视和二次开发”正在变得更重要。
