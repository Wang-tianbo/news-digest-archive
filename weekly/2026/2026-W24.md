## 本周主线

- 本周最值得记住的主线是：`AI 编程代理的竞争从功能展示继续下沉到企业基础设施、运行时治理、模型访问政策和长任务韧性`。

- Anthropic 同时给出两类强信号：一方面发布 Claude Fable 5 / Mythos 5，把前沿能力拆成通用访问与 trusted access；另一方面又因美国政府 directive 暂停 Fable / Mythos 访问，说明模型可用性本身已经进入政策风险层。

- Qwen Code 是中国侧最连续的公开 agent runtime 样本。从 `0.18.0-preview.1/2` 到 `0.18.0` 稳定版，再到后续 durable tasks、worktree isolation、Claude MCP import、ACP permission dialog、token / compression / daemon 修复，本周已经超过普通 CLI 更新，接近可长期跟踪的公开研发 agent runtime。
- Cursor Bugbot、Claude Code nested sub-agents、Claude Agent SDK typed task events、OpenAI Agents SDK sandbox retryability、llama.cpp / DiffusionGemma / Cohere2MoE 等信号共同说明：周内主线不是单个模型能力，而是 agent 工作流、审查、执行、推理和本地部署基础设施的连续变厚。

## 本周评论与判断

- 基于本周样本的判断，`agent runtime governance` 已经从长期议题变成企业落地的直接门槛。权限、runner、content exclusion、model allowlist、sandbox、MCP auth、remote cwd / shell、task lifecycle、token compression 和重复工具调用防护，都是组织敢不敢把任务交给 agent 的前置条件。
- 基于本周样本的判断，GitHub 正在把 Copilot 从“开发者助手”推向“Actions / CI / review / session memory / cost reporting 统一控制面”。Agentic Workflows 的关键不只是自然语言生成 YAML，而是复用 GitHub 既有 runner、审批、权限、计费和审计体系。
- 基于本周样本的判断，Anthropic 的 Fable / Mythos 事件让前沿模型竞争多了一个硬变量：最新模型不一定稳定可用。企业后续会更重视 fallback model、多供应商策略、模型访问审计和政策突发风险，而不只看 benchmark 或上下文长度。
- 基于本周样本的判断，OpenAI 收购 Ona 与 Codex 的远程执行修复应放在同一条线上看。Codex 如果要成为企业长任务 agent，就必须先解决客户云边界、凭据范围、活动日志、review flow、cwd / shell / SQLite / 跨平台路径这些看似底层但决定可部署性的细节。
- 基于本周样本的判断，Qwen Code 的权重需要继续上调，但仍要保持边界：它已经是中国侧最强公开 agent runtime 样本；但“中国侧整体 agent runtime”还需要更多厂商、文档、案例和企业配置面来验证。

## 本周最重要的 10 条更新

### 1. GitHub Agentic Workflows 进入 public preview，并接入 Actions 治理面

- 发生了什么：GitHub 发布 Agentic Workflows public preview，允许用自然语言 Markdown 定义 issue triage、CI failure analysis、documentation updates 等任务，并编译为标准 GitHub Actions YAML；随后补齐 `GITHUB_TOKEN`、组织 AI credits 计费、AI usage report 字段、成本控制和相关安全边界。
- 为什么重要：这把 agent 自动化放进 GitHub 既有 Actions、runner、policy、审批和计费体系。它比单个 Copilot 命令更接近组织级默认入口。
