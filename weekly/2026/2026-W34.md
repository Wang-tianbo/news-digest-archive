## 本周主线

本周真正持续出现的主线，是 AI agent 竞争继续从“谁的模型更会做题”下沉到“谁能把任务、权限、沙箱、队列、审查、恢复和观测做成可长期运行的控制面”。OpenAI 把 cyber-critical pacing、Zero Data Retention、Prompt Caching dashboard、regional processing 和 agent capabilities 继续压进产品/平台层；Anthropic 继续硬化 Claude Code 的 remote control、自托管 runner、MCP 与权限边界；GitHub Copilot 外溢到 Slack、Teams 和 JetBrains enterprise settings；Cursor 把 Cloud Agents 订阅化并进一步推代码托管和 PR 入口；Qwen Code 和 DeepSeek Harness 则把 review、autofix、session、profile bundle 和 unified harness 做成更完整的运行时。

第二条主线是中国侧 agent runtime 不再只是单线样本。Qwen Code、DeepSeek Harness、LobeHub、Cherry Studio、豆包虚拟桌面和 MiniMax M3 把 coding agent、桌面工作台、GUI 自动化、统一 harness 和长上下文/多模态放到同一条产品叙事里。它们还远谈不上成熟生态，但已经足够说明中国公开 agent 竞争开始从“模型名”转向“工作台、运行时和受控执行”。

第三条主线是 model routing 与 cost/control 被明确资本化。Stripe 收购 OpenRouter、OpenAI 的缓存和区域处理、Copilot 的多模型与 managed settings、Latent Space 对企业路由和成本控制的讨论，都在指向同一件事：未来 AI 基础设施的一层核心能力，不是单模型本身，而是模型怎么被选、被计费、被隔离、被审计、被替换。

第四条主线是研究侧开始系统性转向过程与状态。DiG-bench、SPADE、StagedWorkspace、Inducing Task Models from Computer-Use Traces、Fragility of Self-Improving Agents、MidTool、Pandora's AI Model Routing Box、Learning When to Think 这些工作共同说明，评测重点正在从“答对没”转到“如何发现规则、如何复现轨迹、如何组织 workspace、如何分配 compute、如何从 trace 和 data synthesis 中学习”。

## 本周评论与判断

- 基于本期样本的判断：这一周最值得记住的不是任何单次模型 headline，而是 agent 运行时开始像一套真正的系统工程。谁能把 queue、sandbox、review、resume、permission、remote control、workspace 和 telemetry 拼成稳定接口，谁就更接近生产入口。
- GitHub、Cursor、Anthropic 和 OpenAI 在不同表面上收口到同一控制面：repo / PR、IDE / CLI、聊天协作线程、后台任务和企业治理。它们的差异仍然存在，但竞争重心已经相当一致。
- 中国侧不再是“一个模型 + 一个客户端”的单样本故事。Qwen Code、DeepSeek Harness、LobeHub、Cherry Studio 和豆包虚拟桌面共同说明，公开的 agent 产品正在往桌面、GUI、session 和 workspace 方向扩张。
- 模型路由和成本控制不再是背景噪声。OpenRouter 交易、OpenAI 缓存/区域处理、Copilot 多模型、Glean 路由讨论都提示：路由层、计费层和治理层会越来越像基础设施主线，而不是附属配置。

## 本周判断复盘

### 上周判断哪些被验证

- `agent_runtime_governance` 继续被验证，并且边界更清楚了：权限、沙箱、远控、session、review 和资源控制已经不是附属项，而是产品本体。
- `enterprise_agent_control_plane` 继续被验证。Copilot、Claude Code、OpenAI 和 Cursor 都在把 agent 放进企业协作、审计和计费路径里。
- `china_open_agent_runtime` 被继续强化。Qwen Code 和 DeepSeek Harness 形成双主线，LobeHub / Cherry Studio / 豆包把桌面和 GUI 层也拉进来。

### 上周判断哪些被修正

- `agent_evaluation_methodology` 需要进一步拆分。现在不应只写“评测”，而要分成 discovery、workspace/state、trace/replay、self-improvement variance、tool-use data synthesis 和 route/cost allocation。
- `workspace_runtime` 不应再被理解成泛桌面或泛聊天壳。本周更强的风险面来自 repo、PR、远控、跨会话消息、队列、审查和本地执行边界。
- `single_model_headline` 的解释力继续下降。没有控制面、没有治理、没有可复现评测的模型发布，越来越难单独解释赛道变化。

### 本周新增判断

- `model_routing_control_plane` 值得进入长期议题台账。它已经不只是“多模型可选”，而是价格发现、策略控制、企业治理和基础设施采购问题。
- `agent_session_api` 值得单独观察。queue、resume、fork、remote control、review witness、跨会话消息和 workspace 版本契约正在趋向同一层接口。
- `process_trace_infrastructure` 现在同时是产品问题和研究问题。谁能记录、回放、解释并复用轨迹，谁就更可能把 agent 做成可维护系统。

## 本周三大雷达

### AI 新闻

- OpenAI 这周把平台控制面继续做细：cyber-critical pacing、ZDR、Prompt Caching dashboard、regional processing、agent capabilities、Codex queue / dashboard / doctor，说明它在同时推进安全、成本、审计和执行接口。
- Anthropic 继续围绕 Claude Code 的 remote control、自托管 runner、MCP、权限预览和 cross-session 稳定性补课，产品重点已经很明确地落在运行时硬化。
- GitHub 与 Cursor 把 agent 放进更具体的工作流入口：Slack、Teams、JetBrains enterprise settings、Origin code hosting、Cloud Agents subscriptions、subagent VM 分离和 `/goal` / steering 都是在争“工作发生在哪里”。
- Qwen Code 和 DeepSeek Harness 把中文侧的 runtime 线拉得更完整：review、autofix、session 隔离、Web Shell、profile bundle、多模态输入、统一 harness，这些都不是单点功能，而是工作台级组件。
- Stripe-OpenRouter、Mojo open source、OpenRouter 路由经济和 OpenAI 的成本/区域控制一起，说明模型分发层正在被当作可定价、可治理、可替换的基础设施。

### AI 圈博主

#### 中文来源

- 中文社区这一周最稳定的线索，不是某个模型分数，而是工作台与执行层：WorkSwarm、HarnessEval、LobeHub、Cherry Studio、豆包虚拟桌面、Qwen Code、DeepSeek Harness 都在往同一个方向收敛。
- 这些来源反复强调的不是“更强”，而是“更可控、可协作、可审计、可复用”。尤其是桌面、GUI、session、review 和 harness 这些词，已经明显比单纯聊天壳更重要。

#### 英文来源

- Simon Willison 这一周继续提供高密度工程样本：Qwen 3.8 的 overthinking、Mojo open source、smolvm sandbox、ChatGPT search 的 `site:` operator、以及对 TUI 路线的反思，都在把讨论从 hype 拉回可复查的使用边界。
- Interconnects / Nathan Lambert 和 Latent Space 反复把 open-weight economics、model routing、harness evolution 和 `/wayfinder` 这类方法论放在一起，说明英文社区也在从模型能力转向运营和控制面。
- Import AI 与 Another Daily AI Newsletter 继续扮演研究和社区雷达：前者把 discovery benchmark、RSI、harness、agent research 串起来，后者把协作入口、web search tool 和 skill evaluator 放在同一周快照里。

### AI 研究前沿

- `DiG-bench`、`SPADE` 和 `AI4AI-Bench` 把 agent 训练与评测往 discovery、可执行环境和自我改进上推；这类工作不再满足于静态问答，而是直接问“模型能否在未知规则里学会发现规律”。
- `StagedWorkspace`、`Inducing Task Models from Computer-Use Traces`、`Fragility of Self-Improving Agents` 和 `Phantom Gains` 共同说明，workspace 版本、电脑使用轨迹和评测方差已经是 agent 可靠性的核心变量。
- `MidTool`、`Learning When to Think` 和 `Pandora's AI Model Routing Box` 则把工具使用、test-time compute 和路由决策进一步拉回训练/控制问题，而不是仅仅靠 prompt 技巧解释。
- 健康、mobility 和 biomarker 这一组研究信号也在往“低成本可测量的连续表型”靠，但这更像相邻方向，不是本周主线。

### 核心赛道

- 中美大模型：headline 仍在，但解释力下降；真正的差异开始体现在控制面、成本、治理和分发。
- AI 编程代理：这是本周最强主线，且已经从工具层进入运行时和工作流层。
- 开源与基础设施：DeepSeek Harness、Mojo、SPADE、workspace/versioned state、routing layers 都在强化基础设施叙事。
- 研究前沿：process traces、discovery benchmarks、self-improvement variance 和 tool-use data synthesis 是本周最稳定的方向。

### AI 外围情报观察

- 本周最重要的外围变量，不是泛科技新闻，而是模型路由和治理被明显资本化：OpenRouter 被 Stripe 收购、OpenAI 强调 cyber-critical pacing 和 ZDR、企业路由和计费在产品层变细。
- 它为什么会反作用于 AI 主线：agent 进入企业后，成本、区域、保留策略、审计和模型替换会直接决定能否部署，而不是只影响市场叙事。
- 它更像中期趋势，不像短期波动。单条交易或单条政策声明不该过度解读，但“路由 + 治理 + 成本”的组合已经足够构成结构性约束。

### GitHub 热门项目

- `deepseek-ai/deepseek-harness`：本周最强的 open-source harness 信号，且明确把竞品 agent 编进同一层运行/评测平面。
