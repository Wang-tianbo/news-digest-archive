## AI 研究前沿

### Reasoning effort, not tool access, buys first-try reliability in agentic code generation（类型：论文）

- 研究问题：给 agentic coding assistant 增加浏览器测试工具、设计提示和其他工具能力，是否一定能提升一次性可靠性？
- 核心思路：论文于 2026-07-03 01:08:21 Asia/Shanghai 发布到 arXiv，使用 90 次独立 agent runs，让不同模型代际、agent harness、reasoning effort、测试工具和设计提示围绕同一实时 retrospective board 规格实现应用，并用 14 项功能 rubric、视觉质量 review 和成本数据比较结果。
- 为什么可能影响未来：摘要中的关键结论是，capability tier 仍然主导质量；测试工具让成本上升 42%-68%，但未提升功能分数或可靠性；提高 reasoning effort 则提升 first-try perfect rate。这对本期 agent runtime 主题很重要：工具越多不等于越可靠，组织需要评估推理预算、失败类型和部署缺陷。
- 局限 / 待验证点：这是 observational study，任务类型、agent harness 和模型样本有限；是否能推广到多语言仓库、长期多人协作任务和企业 CI/CD 仍需更多复现。
- 研究成熟度：早期论文。
- 可复现状态：论文原文已公开；是否提供完整代码 / 数据集和第三方复现仍需跟踪。
- 原文链接：[arXiv:2607.02436](https://arxiv.org/abs/2607.02436)
- 权威解读：暂无。
- 我的判断：这条研究比“新 benchmark 排名”更值得记录，因为它直接挑战了 agent 产品常见假设：更多工具和更贵 workflow 未必带来 first-try reliability。后续应跟踪是否出现可复现实验包，以及结论是否能在 Claude Code、Codex、Qwen Code、Copilot CLI 等真实工具链上复核。
